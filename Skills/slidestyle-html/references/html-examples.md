이 사례들에서 가져올 공통 원칙은 **연동 강조, 동일 조건 비교, 편집형 레이아웃, 전체에서 사례로 탐색, 근거 연결, 사례와 원리의 연결**이다. 구체적인 구현과 검증은 `../SKILL.md`를 따른다.

## 조합 원칙

- 기본 방향은 **Bartosz의 설명 밀도와 동적인 도식 + Nutshell의 상세 펼치기 + Auto-Animate의 장면 연결**이다. 주제에 맞는 부분만 선택한다.
- 정적인 설명으로 충분한 내용은 그대로 유지하고, 움직임이나 직접 조작으로 변화·관계·차이가 더 잘 이해되는 부분에 HTML 기능을 집중한다.
- 원본이 긴 스크롤 문서나 자유 탐색 도구여도 발표는 한 번의 탐색 입력으로 한 장씩 이동하는 구조를 유지한다. 모든 상세 정보와 시뮬레이션을 조작해야 다음 장으로 갈 수 있게 만들지 않는다.
- 슬라이드 조작 버튼·단축키 안내는 추가하지 않는다. 하단 진행 표시와 콘텐츠 내부의 상세 펼치기·입력 컨트롤은 본문 지침을 따른다.
- 라이브러리 설치가 목적은 아니다. 표현 원리를 참고해 단일 HTML에 필요한 기능만 구현한다. 외부 의존성이 필요하면 오프라인 대체 상태를 마련한다.
- 실제 구현에서는 빠른 이동 시 애니메이션 취소, 콘텐츠 컨트롤과 이동 키의 충돌 방지, 펼친 상태의 가독성과 넘침, 감소된 모션 설정, 정적 출력의 의미 보존을 검증한다.

참고 페이지 확인일: 2026-09-17. 원본의 코드·이미지를 재사용할 때는 해당 라이선스와 출처 조건을 별도로 확인한다.
