# 인창원 특강 캐릭터 기준 인덱스

번들 캐릭터 기준이다. 아래 PNG는 스킬 루트의 assets/characters/에 있다. 원본의 상태 표기를 보존하며 모든 조연을 사용자 승인으로 간주하지 않는다.

## 사용 규칙

- 슬라이드나 장면을 생성하기 전에 주인공 기준 시트와 해당 등장인물의 개별 시트를 실제로 열어 본다.
- 주인공의 현재 기준은 `character-cast-00-protagonist-humorous-face-refined-7_4head-approved-v3.png`이다. 같은 폴더의 주인공 v1·v2는 제작 이력이며 새 작업의 정체성 기준으로 사용하지 않는다.
- 프롬프트에서 주인공 기준 시트는 `style and proportion reference`, 해당 인물의 개별 시트는 `identity reference` 또는 `supporting cast reference`로 명시한다.
- 5등신은 유머, 시행착오, 당황, 발견, 가벼운 설명 장면에 사용한다. 머리 높이는 전체 키의 약 1/5이고, 목·몸통·팔·다리가 7.4등신보다 구조적으로 짧아야 한다. 단순히 7.4등신 인물을 작게 축소하지 않는다. 기본 얼굴은 부드럽고 단순하게 유지하되 상황에 따라 표정을 다양하게 과장할 수 있다.
- 7.4등신은 발표, 회의, 분석, 보고, 멘토링 등 일반 업무 장면에 사용한다. 8등신 패션 모델처럼 늘이지 않는다.
- 한 장면 안에서 얼굴형, 헤어 실루엣, 연령, 체형, 기본 복장과 인물별 핵심 색상을 유지한다.
- 중년 멘토는 40대 현업 팀장·선임으로 표현하며 임원, CEO, 권위적인 정장 인물로 바꾸지 않는다.
- 개별 시트를 덮어쓰지 않는다. 수정 시 새 버전 파일을 만들고 이 인덱스의 현재 기준만 갱신한다.

## 공통 시각 계약

- 1920×1080, 16:9 완성 이미지
- Cool White 배경, Graphite·Deep Navy·Steel Blue 중심, 인물별 제한적 포인트 색상
- 프리미엄 한국 오피스 웹툰, 깔끔한 선화, 절제된 2~3단계 셀 채색
- 사진 질감, 과도한 피부 광택, 로맨스 표지식 미형, 복제된 얼굴 금지
- 캐릭터 시트에는 문구를 넣지 않는다. 최종 이미지 슬라이드에서는 그림과 화면 문구를 함께 생성한다. 사용자의 편집형 요구가 있으면 해당 요구를 우선한다.
