## 확정 구도 계약

### 1. 전체 구조

- 1920×1080, 16:9의 한 장을 **펼쳐진 만화책의 좌우 두 페이지**로 본다.
- 화면 중앙의 세로선을 제본선으로 사용한다.
- 독서 순서는 **좌측 페이지 전체 → 우측 페이지 전체**다.
- 각 페이지 안에서는 **좌상단 → 우측 → 아래 → 우하단**으로 자연스럽게 흐른다.

### 2. 중앙선 절대 금지

중앙 제본선은 장식이 아니라 절대 경계다. 아래 요소는 중앙선을 넘거나 접촉하면 안 된다.

- 컷과 배경 이미지
- 인물, 머리카락, 손과 신체 일부
- 말풍선, 말풍선 꼬리와 대사
- 소품, 서류와 화면
- 효과선, 의성어, 그림자와 색상 강조

중앙선 양쪽에는 흰색 안전 여백을 확보한다. 한 장면을 양쪽 페이지에 걸친 파노라마로 만들지 않는다.

### 3. 컷 분할 기본값

- 기본 컷은 수평·수직의 **90도 직사각형**이다.
- 평범한 대화, 배경 설명, 업무 과정과 일반 반응에는 직사각형 컷을 사용한다.
- 모든 컷을 같은 크기로 반복하지 않고 큰 장면과 작은 반응 컷의 크기 대비를 준다.
- 기본 권장량은 페이지당 4컷, 전체 8컷 전후다.

### 4. 사선 사용 조건

사선은 장식이 아니라 움직임과 감정의 이유가 있을 때만 사용한다.

- 갑작스러운 발견이나 전환
- 빠른 손동작과 시선 이동
- 결심, 충돌, 놀람과 감정 고조
- 마지막 반전이나 강한 종결 장면

페이지당 사선 전환은 보통 0~1회, 많아도 2개 컷 이하로 제한한다. 모든 행이나 모든 컷을 기울이지 않는다.

### 5. 말풍선과 프레임 돌출

- 말풍선은 기본적으로 해당 컷 안에 둔다.
- 대화 중첩, 강조 또는 시선 연결에 도움이 될 때만 내부 컷 경계를 넘길 수 있다.
- 모든 말풍선을 밖으로 빼지 않는다.
- 프레임 밖으로 나온 말풍선도 **같은 페이지 안에서만** 이동한다.
- 중앙 제본선 방향으로 돌출시키지 않는다.
- 인물의 손, 머리 또는 소품이 프레임을 넘는 표현도 핵심 장면에만 제한적으로 사용한다.

### 6. 가독성

- 컷 경계가 사선이어도 얼굴과 글자는 기울이지 않는다.
- 말풍선 하나에는 짧은 대사 1~2줄만 사용한다.
- 그림, 인물의 표정과 동작, 말풍선, 꼬리와 최종 대사·캡션은 같은 생성 과정에서 함께 완성한다.
- 빈 말풍선을 먼저 생성한 뒤 글자를 후합성하거나 잘못된 글자를 덮어쓰지 않는다. 오탈자는 해당 펼침면 또는 해당 컷의 그림과 텍스트를 함께 다시 생성해 고친다.
- 최종 FHD 화면에서 표정과 말풍선이 발표 거리에서도 읽혀야 한다.
- 페이지마다 시선을 붙드는 큰 핵심 컷을 최소 1개 둔다.

## 생성 프롬프트 필수 문구

새 만화 이미지를 생성할 때 아래 조건을 프롬프트에 명시한다.

> Treat the 16:9 canvas as an open two-page comic spread. Finish the left page before reading the right page. Use horizontal and vertical 90-degree rectangular panels as the default. Use diagonal panel edges only for motivated dynamic moments. Speech bubbles may cross an internal panel border only when useful. The vertical center gutter is an absolute hard boundary: no panel, person, object, speech bubble, tail, effect line, shadow, or decoration may touch or cross it.

## 금지 사항

- 모든 컷을 사선이나 사다리꼴로 만드는 구성
- 모든 말풍선을 프레임 밖으로 빼는 구성
- 빈 말풍선·빈 패널을 먼저 만들고 텍스트를 나중에 추가하는 구성
- 기존 그림 위에 박스나 새 글자를 덮어 잘못된 대사를 교정하는 구성
- 좌우 페이지를 한 장면으로 연결하는 중앙선 침범
- 좌측 페이지를 다 읽기 전에 우측 페이지로 시선을 보내는 배치
- 동일 크기·동일 비율의 컷을 기계적으로 반복하는 구성
- 세로 웹툰을 그대로 축소해 FHD에 배치하는 구성
- 원고에 없는 UI, 수치, 성과와 사실을 시각적 재미를 위해 추가하는 것
