# HQ AX Diorama — 캐릭터 스프라이트

3D 공간에 2D 그림 캐릭터를 배치하는 스타일. 기존 3D 도시 구현 대신 새 주제로 관리합니다.
사용자 요구: 캐릭터는 그림으로 생성하고, 모션별 프레임을 한 번에 그린 시트를 잘라 사용합니다. 최종 실행물은 외부 서버·설치 없는 단일 HTML을 지향합니다.
이번 작업: 동일한 사무직 캐릭터의 6개 모션 × 4프레임 시트 생성, 셀 단위 분할·재생을 확인하는 단일 HTML 미리보기. 이 HTML은 캐릭터 자산 검수용이며 3D 오피스 전체 구현은 아닙니다.
모션: 대기, 걷기, 서류 운반, 태블릿 분석, 보고, 완료.

추가 사용자 지시: 그림을 많이 그려도 되니 생성 그림을 사용합니다.
최종 범위: 직원 2명 + AI 로봇 1종, 각 6모션 × 4프레임 = 72프레임. 개별 PNG 및 정렬 아틀라스를 만들고, 3D 오피스 미리보기까지 단일 HTML에 포함했습니다.

## 자율 행동 변경 요청
사용자: '똑같은 동작 말고 알아서 움직여야지'. 동기화된 모션 재생을 제거하고 캐릭터별 독립 행동과 역할별 업무 전달을 구현합니다. 미리보기 모션 카드는 하단의 접힌 검수 영역에만 유지합니다.

추가 요구: 'AI랑 역할분담이 좀 되야할텐데'. 사람은 목표 설정·맥락 해석·추가 분석 요청·최종 승인/보류, AI는 자료 대조·계산·초안·재분석·결정 후 기록을 담당합니다. 역할 권한을 상태 전이로 강제하고 시각적으로 표시합니다.

겹침 수정: AI가 데이터 스테이션 장비에 가려지는 사용자 스크린샷(overlap-reported.png)을 확인했습니다. 스프라이트가 카메라의 하향 기울기를 그대로 따라 몸이 뒤로 누워지는 렌더링을 수직 billboard로 수정하고, hub 작업 위치를 장비에서 떨어뜨렸습니다.

캐릭터 비율 수정: 수직 billboard 전환 후 하향 카메라로 인해 세로 투영 길이가 감소했습니다. 카메라 방향의 수평 성분 길이 역수로 세로 스케일을 보정하고, 발 기준점과 말풍선 높이에도 같은 배율을 반영합니다. 원본 PNG는 변경하지 않습니다.

사용자 보행 개선 요청: 새 그림을 생성해 걷기/운반 각각 8프레임으로 교체합니다. 3종 총 48개 신규 프레임. 이동 거리 기반 보행 재생으로 정지·방향 전환·경로 모퉁이에서의 위상 초기화 문제를 개선합니다.

최종 사용자 요청: '아니 32 프레임으로'. 16프레임 요청을 대체하여 걷기·운반 각각32프레임 적용. 다른 동작은4프레임 유지.

## 2026-09-19 걷기 재수정
- 사용자 피드백: 32프레임 적용 후에도 동작이 이상함.
- 원인: key/mid/quarter 생성 시트의 서로 다른 비율 및 비연속 다리 포즈를 교차 배치.
- 수정: 각 캐릭터·동작의 원본 한 장에서 몸과 다리를 잘라 사용하는 cutout rig. 이동 거리에 맞춰 32개 위상을 생성하고 발 바닥을 정렬. 얼굴과 소품은 같은 원본 유지.
- 32장은 독립 생성 그림이 아닌 동일 그림의 관절 동작 샘플임. 다른 4프레임 업무 동작은 이번 범위 밖.

## 2026-09-19 연결부 잘림 수정
- 사용자 화면: 로봇 허리와 다리 연결부가 수평으로 잘림.
- 몸통을 hip+7 사각형으로 자르던 방식 제거. 다리 윤곽만 몸통에서 분리하고 왼쪽/오른쪽 다리에 개별 부착점 사용. 사람과 로봇의 걷기·운반 모두 반영.

## 전신 모션으로 재제작
- 사용자 명시: 손도 정지되어 있음. 몸/팔다리를 따로 움직이지 말고 전체 전신 모션으로 사용할 것.
- 관절 분리 및 회전 방식 폐기. 걷기32장과 운반32장의 전신 그림을 각자 생성해 셀 전체를 자르고 재생.
- 부분 삭제/부위 회전/팔다리 변형은 사용하지 않음.

## 8프레임으로 변경
사용자 요청에 따라 전신 방식은 유지하고 걷기/운반 각각 8프레임으로 축소. 최신 전신32장 중 0,4,8,12,16,20,24,28을 골라 4x4 아틀라스 구성. 부위별 애니메이션은 사용하지 않음.

## 여자 캐릭터 정지 동작 외형
- 구형 stationary atlas가 새로운 walking atlas와 다른 외형이었던 원인 수정.
- 현재 걷기 그림을 참조한 16개 전신 포즈를 생성해 idle/analyze/report/celebrate 행 교체.
- cut-stationary.ps1로 재생성하며 build.mjs는 employee-b-consistent-atlas.png를 포함.
- 16개 정규화 포즈 및 교육 표지 렌더링 확인. 교육 HTML에도 변경된 디오라마 재포함.
