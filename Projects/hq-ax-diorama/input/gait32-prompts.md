# 32-frame generation
Built-in image_gen. Each original 8-frame cycle uses 8 key drawings, 8 new halfway drawings and 16 new quarter/three-quarter drawings. Three characters, two locomotion cycles each.

## Halfway sheet prompt
Use case: stylized-concept. Create an IN-BETWEEN animation sheet matching the attached 4x4 sprite sheet, not a duplicate. Transparent background with actual alpha, no text/borders/shadows. EXACTLY 4 columns x 4 rows, 16 full-body illustrated poses, equal cells, generous transparent gaps. Same character identity, outfit, head size, stance center, scale, linework, color, camera three-quarter facing RIGHT. The attached sheet has ordinary walk frames 0-7 in its first two rows, and carrying folders frames 0-7 in its last two rows. Draw 16 NEW transition poses: each output cell is the pose HALFWAY IN TIME between the corresponding input cell and the NEXT cell in its 8-frame cycle. Last walk cell transitions to first walk cell; last carrying cell transitions to first carrying cell. These will be interleaved as old0,new0,old1,new1... to produce two 16-frame cycles. Carefully interpolate leg/arm joint angles, heel raising and landing, weight transfer and knee passage. Keep grounded support foot, lift only swinging foot; alternate near and far leg; preserve two arms/two legs, no extra limbs. Avoid repeating an existing pose or copying rows. Keep the hips and head stable; movement comes from smooth smaller joint changes. Carrying rows hold the same cream folder bundle motionless against chest, not a new prop. Consistent same apparent body height every cell and same feet baseline. Premium hand-painted 2D game sprite animation, no 3D render.

## Quarter sheet prompt
Create a 2048x1024 landscape transparent sprite sheet, EXACTLY EIGHT COLUMNS and FOUR ROWS, 32 full-body hand-drawn sprites. Attached image is identity, style and motion reference. Keep identical character, clothes, face, size. NO labels, grid, floor or background, real alpha. Each equal cell is 256x256 with generous empty borders, feet baseline consistent, head same center, complete unclipped bodies. This is a transition-frame animation sheet. First TWO rows contain 16 walking in-betweens. Last TWO rows contain 16 walking-with-folders in-betweens. Reference first two rows give 8 walking keys in reading order; reference last two rows give 8 carrying keys. For EACH adjacent reference pair i -> i+1 (wrapping after key7), create TWO drawings at 25% and 75% of that interval. Thus output walk cells left to right reading order: key0->1 quarter, key0->1 threequarter, key1->2 quarter, key1->2 threequarter, etc through key7->0. Repeat for carrying in last two rows. This is 16 distinct WALK poses plus 16 CARRY poses, total32. Small natural changes in knees, heel lift, arm swing; coherent support foot and swing foot, near and far legs alternate. NO duplicated identical poses. Maintain 3/4 facing screen RIGHT. Steady torso and head; don't bounce or resize. Same cream folders held steady with both hands in carrying poses. Match reference painted ink game art. Optimize for smooth temporal animation rather than decorative illustrations.
