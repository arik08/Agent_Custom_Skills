# HQ AX WORLD

POSCO 경영기획본부를 표현한 자동 실행 3D 경영 시뮬레이션입니다. 모든 숫자, 사건, 판단 및 승인은 교육용 가상 데이터입니다. 실제 POSCO 운영·설비·재무 시스템과 연결하지 않습니다.

## 실행

Node.js 22.12 이상을 설치한 뒤 이 폴더에서 실행합니다.

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 Chrome 또는 Edge에서 여시면 자동 시작합니다. 발표 시 전체화면 버튼 또는 F11을 사용하세요. 최초 패키지 설치 후에는 외부 CDN, 폰트, 이미지나 API 연결 없이 실행됩니다.

```powershell
npm test
npm run build
npm run preview
```

`dist/`는 배포용 정적 파일입니다. HTML 파일 더블클릭 대신 HTTP 서버에서 실행해야 합니다.

## 화면과 조작

- 기본 AUTO MODE: 32초마다 다음 이벤트, 60초마다 게임 세계 1개월. 전체 20개 이벤트가 순차 반복됩니다.
- `속도`: ×1 → ×2 → ×4. 이벤트와 날짜, 도시 움직임이 함께 빨라집니다.
- `일시정지`: 시뮬레이션 시간과 생산·Agent 이동을 정지합니다. 카메라는 목표 위치로 부드럽게 정착합니다.
- `시점`: AUTO → WIDE → FREE. FREE에서 마우스 드래그로 회전하고 휠로 확대합니다.
- 시나리오 선택: 발표 중 원하는 이벤트로 즉시 전환합니다. 진행 중인 미실행 조치는 취소하고, 이미 실행된 KPI 결과는 유지합니다.
- 건물에 마우스를 올리면 담당 조직 및 역할이 표시됩니다.
- 작은 화면에서는 부가 HUD를 줄입니다. 발표는 1440×900 이상의 가로 화면을 권장합니다.

## 주요 연출

16개 조직 시설과 전담 Drone, AX CORE까지 이어진 데이터 네트워크, 20개 사건의 탐지→협업→분석→판단→실행→KPI→피드백 전이를 구현했습니다. AX CORE는 정보 연결 허브이며 판단은 경영진 단계로 전달됩니다. 교육용 자동 승인임을 HUD에 명시했습니다.

첫 사건은 광양 설비 경고입니다. 16초 후 광양 89→81%, 포항 86→92%로 재배분되며 생산 게이지, 증기 및 배관 데이터 흐름에 반영됩니다. 다음 사건은 신규 투자로, 자금·세무·탄소·전략 검토 후 크레인과 시설 성장 애니메이션이 실행됩니다. 반복 투자에서는 같은 부지를 단계적으로 증설하는 표현을 사용하여 무한히 객체가 증가하지 않습니다.

결산 이벤트에는 Finance 조명이 밝아지고, 투자 검토 중에는 WORKLOAD 187% 문구가 나타납니다. 차량, 풍력, 항만, 증기, 홀로그램, 드론, 생산 배관은 평상시에도 움직입니다. 자동 카메라는 이벤트 지역, 협업, 경영 판단, 건설 현장과 도시 전경을 순회합니다.

## 구조와 성능

- `src/simulation.js`: 조직·시나리오 데이터, 독립적인 상태 모델
- `src/main.js`: 절차 생성 3D, 카메라 감독, UI 연결
- `src/style.css`: 반응형 HUD
- `src/simulation.test.js`: 모든 이벤트 생명주기, 생산 재배분, 투자, 장기 순환, 예외 입력 검증
- `validation/`: 브라우저 화면 및 검증 기록

외부 유료 Asset 없이 Three.js procedural geometry를 사용합니다. pixel ratio는 1.5, 그림자는 2048, 이동 물체 수와 로그 길이는 고정됩니다. 저사양 GPU는 브라우저 창 크기를 줄이거나 WIDE로 실행하세요. WebGL 초기화 실패/연결 손실 안내를 제공합니다. 실제 발표용 노트북에서의 FPS는 사전 확인이 필요합니다. 손익 모델은 가상 누적값이며 실제 경제성·안전 판단에 사용할 수 없습니다.
