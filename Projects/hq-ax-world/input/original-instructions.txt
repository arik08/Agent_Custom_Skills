# 프로젝트: HQ AX WORLD

## POSCO 경영기획본부 3D Autonomous Management Simulation

당신은 지금부터 이 프로젝트의 Lead Game Developer, 3D Designer, Simulation Designer, UI/UX Designer 역할을 동시에 수행한다.

내가 세부 구현 방법을 하나씩 지시하기를 기다리지 말고, 아래 요구사항을 바탕으로 스스로 합리적인 세부사항을 결정하여 실제 실행 가능한 결과물을 만들어라.

중간에 사소한 사항을 질문하지 말고 합리적인 기본값을 선택하라.

기획서만 작성하고 끝내지 마라.
반드시 실제 동작하는 프로그램을 구현하고 실행 및 테스트하라.

---

# 1. 프로젝트 목적

POSCO 경영기획본부 구성원 대상 바이브코딩/AX 교육의 오프닝에서 보여줄 3D 데모를 만든다.

일반적인 업무 Dashboard가 아니다.

처음 보는 사람이 다음과 같이 반응할 정도로 시각적으로 재미있는 프로그램이어야 한다.

"이거 게임 아니야?"
"우리 본부를 게임으로 만들었네?"
"AI가 알아서 움직이고 있네?"
"이걸 바이브코딩으로 만들었다고?"

사용자가 직접 플레이하는 게임은 아니다.

기본적으로 AI Auto Mode로 계속 자동 실행되는 "살아 있는 3D 경영 시뮬레이션"이다.

사용자는 가만히 보고만 있어도 된다.

핵심 메시지는 다음과 같다.

"AI가 정보를 탐색하고 분석하고, 여러 업무 Agent가 협업하고, 인간은 중요한 판단에 집중하는 AX 조직"

그리고 더 중요한 교육 메시지는 다음이다.

"복잡한 업무 아이디어도 자연어로 설명하여 실제 동작하는 소프트웨어로 구현할 수 있다."

# 2. 기술 방향

브라우저에서 실행되는 3D Web Application으로 구현한다.

우선순위:

1. 시각적 임팩트
2. 안정적인 자동 시뮬레이션
3. 조직 특색
4. 보는 재미
5. 코드 유지보수성
6. 실제 경영 모델의 정밀성

Three.js 등 적절한 WebGL 기술을 자유롭게 선택하라.

필요하다면 Vite를 사용해도 된다.

특별한 이유가 없다면 과도한 프레임워크 의존성을 피하라.

3D Asset이 없어도 procedural geometry와 low-poly 스타일을 활용하여 충분히 멋지게 만들어라.

외부 유료 Asset에 의존하지 마라.

실행 방법은 최대한 단순하게 만든다.

최종적으로 README에 실행 방법을 작성한다.

# 7. 경영기획DX추진TF팀 / AX CORE

이 게임에서 매우 중요한 시설이다.

건물 이름:

AX CORE

미래적인 AI/Data Center 형태로 만든다.

하지만 AX CORE가 모든 조직을 대신하는 것처럼 표현하지 않는다.

각 전문 조직이 자신의 업무를 수행하며,

AX CORE는

* AI Agent
* Data
* Knowledge
* Automation
* Analytics
* 업무 연결

을 지원하는 Digital/AI Hub 역할을 한다.

모든 주요 조직과 AX CORE 사이에 Data Network가 연결되어 있어야 한다.

평소에는 은은하게 데이터가 이동한다.

중요 Event 발생 시 AX CORE가 활성화되며 데이터 흐름이 강해진다.

# 8. AI AGENT SYSTEM

각 조직에는 작은 AI Agent 캐릭터 또는 Drone/Robot 형태의 존재가 있다.

너무 인간형 캐릭터일 필요는 없다.

작고 귀엽지만 미래적인 Robot/Agent가 좋다.

Agent들은 도시 안에서 실제로 움직인다.

Event 발생 시 관련 조직 Agent들이 움직이며 협업한다.

예:

Business Agent
↓
AX CORE
↓

↓
Strategy Tower

Agent의 머리 위에 작은 상태 표시를 띄운다.

예:

ANALYZING...

SEARCHING...

CALCULATING...

SIMULATING...

REVIEWING...

EXECUTING...

MONITORING...

# 9. AUTO SIMULATION

게임은 실행하자마자 자동으로 돌아간다.

사용자 입력이 없어도 된다.

게임 내부 시간은 현실보다 빠르게 흐른다.

예:

1분 = 게임 세계 1개월

또는 화면 연출상 더 자연스러운 속도를 스스로 결정한다.

화면에 Game Date를 표시한다.

예:

2030 MAR

AUTO MODE ●

Simulation Speed x4

기본적으로 계속 Event가 발생한다.

Event 간격은 너무 빠르거나 느리지 않게 약 20~45초 수준으로 조정한다.

12. Gwangyang Gas Equipment Warning
13. Industrial Gas Demand Surge
14. Major Customer Contract Opportunity
15. Logistics Disruption
16. Financing Cost Increase
17. Tax Risk Detection
18. Closing Season
19. New AI Automation Opportunity
20. Unexpected Productivity Improvement

필요하다면 더 추가한다.

각 Event는 단순 Notification으로 끝나면 안 된다.

Event
→ Detection
→ Agent collaboration
→ Analysis
→ Decision
→ Action
→ KPI impact
→ Feedback

이라는 Life Cycle을 가진다.

# 14. CAMERA DIRECTOR

매우 중요하다.

사용자가 조작하지 않아도 재미있어야 한다.

자동 Camera Director를 구현한다.

평상시:

도시 전체를 천천히 Orbit.

Event 발생:

관련 지역으로 부드럽게 이동.

Agent 활동:

Agent 또는 Data Flow를 따라간다.

Major Decision:

Strategy Tower 또는 AX CORE로 이동.

Project Construction:

Construction Site로 이동.

Event 종료:

다시 도시 전체 View로 돌아간다.

카메라 이동은 갑작스럽지 않고 cinematic하게 한다.

가능하다면 Camera Director가 여러 Shot을 선택하도록 한다.

Wide Shot
District Shot
Building Close-up
Agent Follow
Event Focus
Return to City
