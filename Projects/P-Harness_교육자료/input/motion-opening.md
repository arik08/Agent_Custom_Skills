- 브라우저 네트워크 없이 폰트·그림·스크립트가 동작해야 한다.

## 소리와 템포 후속 수정
- 사용자 피드백: “소리 안나는데? 그리고 너무 호흡이 길어.”
- 26초 초안을 15초로 압축. 전환을 0.48초에서 0.26초로 줄이고 등장 속도·정지 시간을 함께 조절한다.
- 무음 자동 재생을 없애고, ‘소리와 함께 재생’ 버튼의 사용자 동작으로 오디오를 시작한다.
- 일시정지·재생 완료 상태에서 소리를 켜면 재생을 함께 시작한다. 완료 상태라면 처음으로 돌아간다.
- 낮은 출력과 저음 중심의 비트를 개선한다. 160 BPM, 중음역 멜로디와 정규화된 출력, 실제 오디오 출력 미터를 사용한다.

## 강조 메시지 후속 수정
- “당신의 업무에, AI의 실행력을”보다 AI를 통해 사내외 정보를 바탕으로 빠르게 조사하고 보고서까지 만드는 점을 강조한다.
- 결말 문구는 “사내외 정보로, 빠른 조사부터 보고서까지.”로 변경한다.
- 첫 장면·자료 도형·과정 설명·산출물 문구·텍스트 설명에도 같은 메시지를 반영한다. 15초 길이를 유지한다.
- 사내 자료의 자동 직접 접속을 의미하지 않는다. 첨부 자료와 연결 가능한 정보 활용이라는 기존 교육자료의 범위를 유지한다.

## 배경 후속 수정
- 사용자는 모눈종이 스타일을 선호하지 않는다. 전체 장면에서 격자·사선·반복 배경선을 제거한다.
- 네이비·블루 그라데이션과 밝은 옅은 블루 그라데이션으로 장면을 구성한다. 본문 정보 구분선·연결선은 필요한 부분에 유지한다.

## 메시지 반복 제거
- 사용자 피드백: “메세지가 너무 같은것만 반복되는데.”
- 모든 장면이 정보→조사→보고서를 되풀이하지 않도록 문제→요청→기능→정보 연결→결과물→브랜드의 서로 다른 역할로 나눈다.
- 핵심 슬로건 “사내외 정보로, 빠른 조사부터 보고서까지.”는 마지막에만 사용한다. 설명용 문서 제목과 단계명은 유지하되 같은 홍보 문구를 여러 장면에 반복하지 않는다.

## 강조 범위 정정 — 최신 기준
- 사용자는 사내외 정보 조사·보고서를 **추가로 강조할 활용 사례**로 제시했다. 그것만이 P-Harness 전체 가치이거나 유일한 메시지라는 뜻은 아니다.
- 앞서 해당 사례를 전체 슬로건으로 좁힌 해석을 바로잡는다. 바로 위의 “마지막에 해당 슬로건만 사용” 방침은 대체한다.
- 전체는 AI 업무 공간 소개→다양한 업무→Model·Skill·MCP→대표 조사 사례→결과물 활용→브랜드로 구성한다.
- Model은 업무에 맞는 AI와 추론 수준, Skill은 반복 업무의 절차·기준, MCP는 필요한 도구·정보 연결을 설명한다.
- 사내외 정보로 빠르게 조사하고 보고서까지 만드는 점은 대표 사례 한 장면에서 강조한다. 마지막은 “선택부터 실행, 결과물까지. 당신의 AI 업무 공간.”으로 마무리한다.

## 사운드 재제작 및 전체화면 안내 (최신 기준)
- 사용자 피드백: “소리 넘 별로임. 센스껏 다시!” 반복 합성 비트를 제거하고 실제 피아노 음색, 짧은 시작·마무리, 부드러운 전환음으로 교체한다. 위의 160 BPM 합성 비트 기준을 대체한다.
- 음원은 외부 로딩 없이 HTML에 내장한다. 샘플 원본 출처·라이선스·편집 사실을 기록한다.
- “이건 굳이 보여주지 말고”의 대상은 전체화면 아래에 뜨던 단축키 안내다. 후속 명확화에 따라 일반 화면의 단축키 안내는 유지하고 전체화면 안내만 제거한다.
- 영상 영역 우클릭으로 전체화면에 진입하며 다시 우클릭하면 종료한다. F와 Esc, 기존 전체화면 버튼도 유지한다.
- 영상 내용·그라데이션·15초 타이밍은 변경하지 않는다.

## 광고 음악 방향 정정 — 현재 최우선 기준

## AI와 네 개 스킬 심볼 — 최신 기준

- 중앙 원에 AI를 놓고 검색·분석·문서·검토 아이콘을 담은 네 원을 상하좌우에 연결한다. 이는 스킬 유형의 개념 표현이며 실제 등록된 스킬 네 개를 뜻하지 않는다.
- 업무 소개·기능 연결·조사 사례·마지막 브랜드 장면 네 군데에서 공통 심볼을 사용한다.
- 후속 피드백: “AI 글자가 중심이랑 어긋남. 뭔가 흐린것도 맘에 안들고”. AI 글자는 확대되는 작은 비트맵 대신 최종 Canvas에 직접 그리며 실제 글자 윤곽으로 가로·세로 중심을 맞춘다. 원·아이콘의 선과 어두운 배경의 색 대비도 보강한다.

## 전체화면 선명도
- Canvas 내부 해상도를 실제 표시 크기 × 기기 픽셀 배율에 맞춘다. 기존 1.5배·DPR 2배 제한을 제거한다.
- 글자는 작은 캐시 이미지 확대 대신 최종 Canvas에 직접 렌더링한다. 보고서 그림 캐시도 배율에 맞춰 다시 생성한다. 화면 전환·모니터 배율 변경에 대응하며 기존 조판·장면 길이는 유지한다.


## 연결선·AI 중심 정렬
- 기능 연결 장면의 분기선부터 AI 마크까지 같은 밝은 블루를 사용한다.
- AI 글자는 실제 글자 잉크의 가로 무게중심을 원 중심에 맞추고 세로는 글자 윤곽 중심에 맞춘다. 공통 마크에 적용한다.


## 25초 버전 추가
- 사용자 요청에 따라 기존 16초 버전과 별도로 25초 HTML을 제작한다. 기존 디자인·기능을 유지하고 장면별 읽을 시간을 늘린다. 음악은 템포를 유지하여 반복 구간을 연결하고 원곡 엔딩을 보존한다.


## 25초 버전 동작 속도 정정
- 빠른 등장 후 긴 정지가 반복된다는 피드백에 따라 장면 내부 시간 배율을 [.85,.62,.75,.84,.50,.80]으로 조정한다.
- 0·3·6·11·16·21초 장면 시작과 총 25초, 음악은 유지한다. 기존 등장·연결·전개를 장면 시간에 분산하고 전환은 0.42초로 늘린다. 새로운 장식 움직임은 추가하지 않는다.
