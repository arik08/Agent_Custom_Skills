01 · OVERVIEW

P-Harness는 사무계 업무 지원을 위한 AI Agent입니다

P-Harness는 질문에 답하는 채팅을 넘어, 사용자가 제공한 문서와 연결된 데이터·업무 지식을 바탕으로 분석하고 실제 산출물을 만드는 업무 수행 환경입니다. 브라우저에서 접속하므로 개인 PC에 별도 프로그램을 설치할 필요가 없으며, 다수 사용자를 지원하는 분산 처리형 구조로 운영됩니다.

바로 접속별도 설치 없이 사내 환경에서 사용할 수 있습니다.
다수 사용자 지원Google Cloud 기반 분산 처리형 시스템으로 운영됩니다.
DRM 문서 인식다운로드한 사내 DRM 문서를 첨부하여 분석할 수 있습니다.

P-Harness를 잘 쓴다는 것은 “좋은 질문”만 하는 것이 아니라, 적절한 자료 · Skill · MCP · 모델 · Effort를 함께 선택해 검증 가능한 결과물을 만드는 것입니다.

02 · MYHARNESS VS P-HARNESS

두 시스템의 방향은 같고, 운영 환경과 적용 범위가 다릅니다

구분MyHarness (PoC 버전, 2026. 4. 27 ~ )P-Harness (정식 출시, 2026. 10. 1 ~ )
운영 위치사무용 개인 PC에서 시험 가동Google Cloud에서 구동
운영 구조개인·로컬 중심의 사용자 시스템다수 사용자를 커버하는 분산 처리형 시스템
업데이트업데이트 빈도가 높고 신기능을 먼저 시험검증된 기능을 안정적으로 점진 적용
문서 활용개인 PC 로컬 작업공간 중심DRM이 적용된 사내 문서도 인식 가능
관계새 기능의 활용성과 사용성을 검증MyHarness에서 검증된 기능을 순차적으로 반영
한 줄 정리
MyHarness가 빠르게 기능을 시험하는 실험 환경이라면, P-Harness는 검증된 기능을 다수 사용자가 안정적으로 활용하는 사내 서비스입니다.

04 · INPUT & SHORTCUTS

@와 $, 두 기호부터 익히세요

@ 파일분석하거나 수정할 산출물 파일을 링크합니다. 파일명을 글로만 쓰는 것보다 대상을 정확히 지정할 수 있습니다.
$ 확장업무 처리 방식을 담은 Skill이나 외부 데이터 연결인 MCP를 호출합니다.
Shift＋Enter메시지를 보내지 않고 입력창에서 줄을 바꿉니다.
Ctrl＋EnterAI가 작업 중일 때 현재 작업을 방해하지 않고 다음 요청을 대기열에 추가합니다.
Enter대기 중에는 질문을 전송합니다. 작업 중 그냥 전송하면 현재 답변의 방향에 영향을 주는 추가 지시가 됩니다.
20줄 초과긴 글을 붙여넣으면 입력창을 가득 채우지 않도록 별도의 카드 형태로 접혀 표시됩니다.

06 · EFFORT

모델 등급과 Effort를 함께 조절하세요

Effort는 AI가 답을 만들기 전에 얼마나 깊게 검토할지를 정하는 값입니다. 높을수록 항상 좋은 것이 아니며, 시간과 비용도 함께 늘어날 수 있습니다. 좌측 하단 설정에서 작업 난이도에 맞게 선택합니다.

모델 수준권장 Effort이유
상위 모델Low기본 성능이 높아 일반 사무 작업은 낮은 추론노력으로도 충분합니다.
중급 모델Low ~ Medium검색·분석·보고서의 난이도에 따라 조절합니다.
하위 모델Medium ~ High복잡한 지시를 안정적으로 처리하도록 검토 여유를 늘립니다.

작업 난이도는 대체로 다음 순서로 높아집니다

질의응답개념·요약
웹검색＋답변자료 탐색·출처
세로형 웹 보고서분석·차트·구성
가로 슬라이드 보고서HTML·PDF·PPTX
코딩구현·디버깅·검증
실무 권장
코딩을 제외한 일반 업무에서는 Effort를 무조건 높게 설정할 필요가 없습니다. 먼저 권장 범위에서 실행하고, 누락이나 논리 오류가 반복될 때 한 단계 높이는 방식이 효율적입니다.
07 · DOCUMENT & ARTIFACT

“보고서 만들어줘”라고 하면 HTML 보고서가 기본입니다

별도 파일 형식을 지정하지 않고 “~에 대해 보고서 만들어줘”라고 요청하면 세로형 HTML 보고서 생성이 기본 트리거로 작동합니다. PPTX, PDF, Excel 등 원하는 형식이 있다면 요청에 명시하십시오.

STEP 1자료 첨부원본·기준 문서를 연결합니다.
STEP 2목적 설명독자와 의사결정 목적을 씁니다.
STEP 3형식 지정HTML·PDF·PPTX 등을 정합니다.
STEP 4검증 요청숫자·출처·누락을 확인시킵니다.
STEP 5Viewer 확인내용과 레이아웃을 검토합니다.

AI가 생성하는 문서의 기본 표현

ECharts수치 비교, 추세, 비중 등 그래프를 표현하는 기본 차트 도구입니다.
Mermaid ChartWorkflow, 절차, 관계와 의사결정 흐름을 표현하는 기본 다이어그램 도구입니다.
출처 표시외부 자료나 근거 문서를 활용한 주장에는 출처를 연결합니다.
@회의자료.pptx와 @실적.xlsx를 중심으로 경영층 보고서를 만들어줘.
결론을 먼저 제시하고, 핵심 실적·원인·리스크·의사결정 요청 순서로 구성해줘.
정량 비교는 ECharts, 업무 절차는 Mermaid로 표현하고 모든 주요 사실에 출처를 표시해줘.
최종 결과는 세로형 HTML 파일로 작성해줘.

09 · WHY AGENT SKILL?

Skill은 도메인 전문가가 직접 만드는 업무 실행 방식입니다

기존 시스템 개발에서는 도메인 전문가는 개발을 모르고 개발자는 업무의 세부 판단을 알기 어려워, 요구사항을 맞추기 위한 회의와 수정에 많은 시간과 비용이 들었습니다. Agent Skill은 업무 전문가가 AI와 대화하며 지식·절차·평가기준·산출물 형식을 직접 만들고 반복 개선하는 방식으로 이 간극을 줄입니다.

기존 맞춤 개발

  • Frontend와 Backend를 별도로 설계
  • 업무 지식을 개발 요구사항으로 번역
  • 개발·테스트·배포에 긴 리드타임
  • 변경 시 다시 개발자와 협의

Harness AI＋Skill

  • 공통 채팅 UI와 실행 프로그램 재사용
  • 업무 전문가는 도메인 지식에 집중
  • 대화로 기초 Skill을 빠르게 제작
  • 결과물 테스트와 피드백으로 반복 개선
장단점은 분명합니다.
개별 Vibe Coding으로 독자적인 AI Agent를 만드는 것보다 화면과 기능의 자유도는 낮습니다. 반면 범용 채팅 UI로 처리 가능한 업무라면 Skill만 제작하는 방식이 개발비와 유지보수 측면에서 유리합니다.

Skill 제작·수정 시연 절차

1. 자료＋설명 제공규정, 우수 사례, 판단기준과 원하는 결과물을 Agent에 전달합니다.
2. 기초 Skill 제작업무 목적, 입력, 절차, 금지사항과 출력 형식을 정의합니다.
3. 성능 테스트실제 또는 비식별 샘플로 보고서 등 결과물을 생성합니다.
4. 피드백 반복누락·오판·표현 문제를 반영해 Skill을 점진적으로 다듬습니다.
첨부한 업무지침과 우수 보고서 예시를 바탕으로 이 업무 전용 Skill을 만들어줘.
입력자료 검증, 업무 절차, 판단기준, 반드시 물어볼 질문, 금지사항과 최종 보고서 형식을 포함해줘.
기초 Skill 작성 후 샘플 자료로 테스트하고 개선점도 정리해줘.
10 · WHAT IS MCP?

MCP는 AI Agent가 데이터를 가져오는 표준 연결 방식입니다

Skill = 어떻게 처리할지업무 절차, 판단기준, 질문 방식과 결과물 형식을 정의합니다.
MCP = 어디서 가져올지외부 데이터, 공공기관 정보와 사내 업무 시스템을 연결합니다.

입력창에서 $를 누르면 등록된 Skill과 MCP를 조회할 수 있으며, 목록에서 활성화·비활성화할 수 있습니다. 이름을 추측하기보다 설명을 읽고 업무 목적에 맞는 연결을 선택하십시오.
