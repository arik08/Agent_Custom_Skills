# P-Harness 교육자료 요구사항

작성일: 2026-09-28

## 제공 자료
- `참고자료/feedback.md`: 상사 피드백과 필수 교육 내용.
- `참고자료/P-Harness_사용법_v3.html`: 기존 사용법 매뉴얼.
- 참고자료 위치는 최초 `참고자료/`에서 현재 `input/참고자료/`로 변경됨. 현재 위치를 기준으로 사용한다.

## 사용자와 합의한 사항
1. 사내 교육과 교육 후 업무 중 참고에 사용할 완성도 높은 HTML 매뉴얼을 만든다.
2. 세로형 HTML 한 개만 제공한다. 가로형 슬라이드나 별도 발표 버전을 제작하지 않는다. 유지보수할 콘텐츠를 이중으로 만들지 않는다.
3. 고정 목차에서 모든 장과 세부 항목으로 즉시 이동할 수 있어야 한다.
4. 실제 화면 캡처, 개념도, 결과물 예시를 활용하고 이미지는 확대할 수 있게 한다.
5. 본문 검색과 현재 읽는 목차 강조를 제공한다.
6. 문서 어디서든 우클릭하면 전체화면으로 진입하고, 다시 우클릭하면 해제한다. Esc와 화면 내 버튼도 제공한다.
7. 전체화면에서도 동일 본문과 세로 배치를 유지한다. 목차는 접고 펼칠 수 있다.
8. 업무 사례를 따라 학습하고 필요한 기능은 나중에 찾아볼 수 있도록 구성한다.
9. 상세 기획 도출 후 사용자가 HTML 제작을 요청했다. 기획안대로 구현하고 실제 브라우저에서 검증한다.
10. MyHarness 프로젝트를 P-Harness와 거의 같은 참고 구현으로 사용한다. P-Harness와의 차이는 구분한다.
11. 필요한 화면은 직접 실행하여 FHD(1920×1080) 기준으로 캡처한다.

## 설계 시 반영할 사항
- 단일 파일 안에 핵심 이미지·스타일·스크립트를 포함하여 배포 편의성을 확보한다.
- 영상과 외부 원문 링크는 인터넷 접근이 필요하므로 핵심 설명을 대체하지 않는다.
- 실제 제품 기능·모델·단가·지원 환경은 제공 자료만으로 현재 동작을 확정하지 않는다.
- 실제 화면이 없으면 임의의 UI를 실제 제품 화면처럼 제시하지 않는다.
- 브라우저 정책으로 전체화면이 제한될 때도 읽기·목차·검색은 정상 동작해야 한다.

## 사용자 후속 수정
- 전체 색상은 녹색·청록색 대신 포스코 블루(#05507D)와 연한 블루 계열로 통일한다.
- 문서 명칭에서 “실무 가이드”는 “사용자 가이드”로 변경한다.
- 목차와 본문의 세로 스크롤바는 거슬리지 않는 연한 블루그레이로 표시한다.

## 시각 구성 개선 승인
- 사용자가 밋밋한 구성을 개선하도록 요청하고, 제안 검토 후 제작을 승인했다.
- 문제·퀴즈·정답 선택형 활동은 추가하지 않는다.
- 포스코 블루 표지에 요청과 보고서 구성 예시를 연결하고, 장 제목에는 의미 있는 이모지·큰 번호·색상 띠를 사용한다.
- 실제 화면에는 번호와 설명을 덧붙이고, 요청 방법은 전후 비교·흐름·핵심 문장으로 읽는 리듬을 만든다.
- 이모지는 장 제목·안내·팁에 제한한다. 기존 내용과 목차, 검색, 확대, 전체화면, 연한 스크롤바와 단일 세로형 HTML을 유지한다.

## 첫 화면 후속 조정
- 첫 화면의 진한 사각 배경을 밝은 바탕으로 바꾸어 본문과 자연스럽게 연결한다. 포스코 블루는 제목과 주요 버튼에 사용한다.
- 우측 요청·보고서 예시의 좌우 경계를 맞추고, 상단 도구 버튼의 높이와 아이콘·문구 정렬을 통일한다.

## 도식과 문서의 시각 검수
- 사용자가 지적한 ECM 도식 제목 넘침을 계기로, 페이지 전체뿐 아니라 SVG 내부 글자와 상자 경계도 검수한다.
- 긴 한글·영문 제목, 공백 없는 문자열, 여러 줄 설명에도 글자를 축소·누락하지 않고 줄바꿈과 높이 확장으로 대응한다.
- 최종 파일 수정 후 전체 본문의 글자 넘침·요소 겹침과 좁은 화면을 검사하고, 실제 렌더링을 확인한다.

## 모델 이름 표기
- 모델은 Luna, Terra, Sol처럼 축약하지 않고 GPT-5.6-Luna, GPT-5.6-Terra, GPT-5.6-Sol처럼 버전을 포함해 표기한다. Gemini도 제공 자료의 버전을 포함한 Gemini-3.8-Flash로 표기한다.

## 모델 누락 보완과 학습 순서 조정
- GPT-6-Astra·GPT-6-Sol·GPT-6-Luna를 모델 안내에 포함한다. 원본의 출시 정보와 P-GPT 미적용 구분은 자료 작성 당시 기준임을 명시한다.
- 모델별 출력단가와 상대비용은 원본 비교값으로 표시하며 현재 요금이나 전체 비용으로 단정하지 않는다.
- 장 순서를 모델과 Effort 선택 → Skill 활용하기 → MCP 활용하기 → 일을 잘 맡기는 요청법으로 바꾼다. 본문, 장 번호, 목차와 기획안에 같은 순서를 적용한다.

## Skill·MCP 목록을 보는 기본 경로
- 좌상단 `/` 모양의 “명령어” 버튼을 눌러 스킬 또는 MCP 항목을 펼쳐보는 경로를 우선 설명한다. MyHarness 실제 화면에서 이름과 동작을 확인했다.
- 채팅창의 `$` 또는 Skill 및 MCP 호출 버튼은 특정 도구를 요청에 직접 지정하는 보조 방법으로 배치한다. `@`는 파일 연결임을 구분한다.
- 첫 업무 안내·Skill 장·MCP 장·빠른 참고에 같은 우선순위를 적용하고 명령어 진입·스킬 목록·MCP 목록을 1920×1080으로 캡처한다.

## 정보 밀도 개선
- 장 제목·문단·표·카드·안내 박스의 반복 여백을 줄여 한 화면에서 더 많은 내용을 읽게 한다. 본문 글자 크기와 핵심 내용은 유지한다.
- 긴 단계는 촘촘한 행으로 배치하고, 화면 안내는 넓은 화면에서 설명과 캡처를 나란히 보여준다. 좁은 화면에서는 하나의 열로 이어진다.
- 큰 전체 화면 캡처는 본문에서 작은 미리보기로 제공하고 기존 확대 기능으로 FHD 원본을 볼 수 있게 한다. 별도의 밀도 모드·버전은 만들지 않는다.
- 수정 전후 문서 높이와 주요 안내 영역 높이를 같은 해상도·펼침 상태로 측정하고, 전체 레이아웃과 목차·검색·이미지 확대를 재검수한다.

- 표지의 요청 예시에서 따옴표 안 문장의 강제 줄바꿈을 제거한다. 폭이 충분하면 한 줄로 표시하고 좁은 화면에서는 자연스럽게 줄바꿈한다.


## 시스템 안내서·교과서 구성으로 개선 (최신 방향)
- 자료의 중심은 P-Harness라는 시스템의 구성과 기능을 알려주는 것이다. 업무 요청 훈련이나 한 가지 보고서 사례가 전체를 이끌지 않는다.
- 훌륭한 교과서처럼 전체 구조 → 구성요소의 역할 → 실제 화면과 사용법 → 활용·확인으로 설명한다.
- 사용자가 짧게 훑어도 무엇을 설명하는지 파악할 수 있게 전체 지도, 모델/Effort 비교, Skill 기능 분류, MCP 정보원 연결 지도, 화면 영역 지도, 산출물 유형을 구분된 시각 구조로 제시한다.
- 첫 화면은 밝은 포스코 블루 계열의 시스템 구성도로 바꾼다. 기존 요청·보고서 표지 구성은 대체한다. 경쟁사 보고서 예시는 활용 장에서 설명한다.
- 기존의 상세 정보와 높은 읽기 밀도를 유지한다. 같은 내용을 말하는 도식은 중복 추가하지 않는다.
- 세로형 HTML 하나, 모델→Skill→MCP 순서, / 명령어 우선 설명, FHD 원본 확대, 목차·검색·우클릭 전체화면, 문제·퀴즈 없음은 유지한다.

## 역할 설명 패널 경계 수정
- 모델·Skill·MCP·Harness 선택 버튼과 설명을 하나의 패널로 묶는다. 중간에 끊긴 것처럼 보이는 테두리와 겹친 둥근 모서리를 없애고, 탭 하단과 탭 사이 구분선을 완결한다.
- 모바일 두 줄 버튼에서도 구분선과 선택 상태를 유지한다.

## 단일 HTML 이미지 저장 구조
- 본문의 이미지는 ID 참조만 두고 Base64 데이터는 HTML 맨 아래 한곳에 모은다. 외부 이미지 파일 없이 전달할 수 있어야 한다.
- 스크린샷은 FHD 해상도를 유지한 WebP로 압축하고 중복 이미지는 공유한다. 벡터 도식은 선명도를 위해 SVG로 유지한다.

## 별도 교육 오프닝 모션그래픽 (2026-09-29)
- 기존 사용자 가이드와 별개인 광고 스타일 모션그래픽을 제작한다.
- 가로 16:9 교육 오프닝이며, JavaScript가 중심인 웹페이지 형태로 제공한다.
- 상세 요구사항과 첫 시안 구성은 `motion-opening.md`에 기록한다. 이 요청은 기존 가이드의 세로형 단일 문서 구성 변경을 뜻하지 않는다.
- 오프닝 후속 피드백으로 재생 시간을 26초에서 15초로 줄이고, ‘소리와 함께 재생’ 시작 버튼과 충분한 오디오 출력으로 변경한다. 종료 후 소리를 켜도 다시 재생되어야 한다.
- 오프닝은 “사내외 정보로, 빠른 조사부터 보고서까지.”를 중심 메시지로 삼는다. AI로 사내외 정보를 활용한 빠른 조사와 보고서 작성을 강조하도록 앞 장면과 결말을 함께 맞춘다.
- 오프닝 배경의 모눈종이·반복 선 패턴을 제거하고 네이비·블루 및 옅은 블루 그라데이션을 적용한다.
- 같은 메시지 반복을 없애고, 장면을 문제→구체적인 요청→구성요소→정보 연결→결과물→브랜드로 나눈다. 핵심 슬로건은 마지막 장면에만 쓴다.
- 최신 정정: 사내외 정보 조사·보고서는 추가로 강조할 대표 활용 사례이며 P-Harness 전체 메시지를 이것으로 한정하지 않는다. AI 업무 공간, 다양한 업무, 모델·추론 수준 선택, Skill, MCP, 결과물 검토·수정·활용을 고르게 보여준다. 결말은 “선택부터 실행, 결과물까지. 당신의 AI 업무 공간.”으로 변경한다.

## 오프닝 사운드·전체화면 후속 수정 (2026.09.29)
- 반복 전자음 비트를 실제 피아노 음색과 절제된 전환음으로 교체한다. 기존 영상 구성·15초 길이는 유지한다.
- 전체화면의 단축키 안내만 제거하고 일반 화면의 안내는 유지한다. 영상 영역 우클릭으로 전체화면 진입·종료를 지원한다.

## 오프닝 음악 최신 정정
- 15초 광고에 맞게 강한 비트와 멜로디를 원한다. 직전의 느슨한 피아노 중심 사운드는 대체한다. 킥·스네어·베이스와 짧은 멜로디 훅이 처음부터 들어오는 구성을 적용한다.

## 목차 단순화 (최신 우선)
- 왼쪽 목차는 00~12 장 제목만 표시한다. 하위 목차, +/− 펼침 버튼, 모두 접기 버튼을 제거한다.
- 현재 읽는 장을 강조하며 세부 항목은 본문 링크와 검색으로 이동한다.

## 회사 발표용 음악 — 최신 정정
- 사용자 피드백: “게임같아. 회사에서 발표하는건데 그래도.”
- 강한 비트와 멜로디 요구는 유지하되, 높은 합성 리드·게임 느낌·과한 EDM 음색은 배제한다. 느린 피아노로 되돌리는 뜻이 아니다.
- 현재 구현은 기업용 기타 중심 곡 Running Out of Time / Ahjay Stelino / Mixkit의 완성된 연주에서 15초 구간을 편집한 corporate-v4다. 음악 출처·사용 조건을 기록하고 영상에 내장한다.

## 사운드 최종 정정 — 드럼 중심
- 사용자: “멜로디 빼고 드럼 소리 중심으로 임팩트있게”. 앞선 멜로디 추가·기업용 기타 음악 기준을 대체한다.
- 멜로디·코드·피아노·신스·베이스 악기 및 배경 음악을 제거하고 킥·스네어·하이햇·드럼 필인·타격음만 사용한다. 회사 발표에 맞게 과도한 게임 음색을 피한다.
- 현재 구현은 128 BPM, 15초, 짧은 필인과 장면 전환 악센트, 마지막 단일 드럼 타격으로 구성한 drums-v5다.

- H 대신 연결 심볼 1안을 선택한 뒤, 사용자가 “AI 중심으로 4개의 스킬(원 안에 아이콘)이 감싸는 구조”로 구체화했다.

## 사내 MCP Provision 상태 안내
- posco- 접두사의 MCP는 미래 사내 연동을 위한 Provision(사전 준비 항목)이며 현재 대부분 실제로 동작하지 않음을 본문과 표에 명시한다. 목록 등록·활성 표시를 실제 조회 가능 상태로 해석하지 않도록 설명한다.


- 최종 정정: posco-ecm은 일부 구현된 상태이나 현재 사용 가능한 연결로 취급하지 않는다. Provision 표에 포함하고 구현 완료라는 설명은 하지 않는다.

- 모델명 정정: GPT-5.6-Astra는 존재하지 않는 모델이므로 가격표의 해당 행($50, 약 42배)을 삭제한다. GPT-6-Astra와 혼동하지 않는다.

- Skill 이름과 구성은 수시로 바뀌므로 본문·분류 도식·제작 요청문에 특정 등록 이름을 고정하지 않는다. 활용 분야·하는 일·선택 기준을 설명하고 좌상단 / 명령어의 최신 목록에서 확인하도록 안내한다. 캡처는 촬영 당시 예시로 구분한다.

- 최종 범위: 어떤 Skill이 있는지 소개하는 활용 분야 표·등록 예시·분류 도식 자체를 삭제한다. 목록을 여는 방법과 선택·사용·제작 절차만 남긴다.

- 공통 흐름도의 상하 여백과 카드 높이를 줄이고 흐름도 확대 버튼을 제거한다. 실제 화면 캡처 확대 기능은 유지한다.

- 참고 영상 설명은 제작 경위(상사 피드백)를 빼고 “Harness 개념을 이해하는 데 도움이 되는 참고 영상입니다.”로 안내한다.

- 참고 영상 최종 설명: “일반적인 Harness 개념을 설명하는 영상이며, P-Harness 사용 안내 영상은 아닙니다.”로 별개 영상임을 명시한다.
