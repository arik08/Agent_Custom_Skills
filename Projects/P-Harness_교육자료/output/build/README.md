# 빌드와 검수

최종 배포 파일은 상위 폴더의 `p-harness-guide.html` 하나입니다.

## 빌드

`python Projects/P-Harness_교육자료/output/build/build.py`

기존 Python의 Pillow와 Windows 맑은 고딕 글꼴을 사용해 도식의 글자 너비를 계산합니다. 제목이 길어지면 줄바꿈과 도식 높이 조정으로 대응합니다.

## 변경 후 검수

1. `node Projects/P-Harness_교육자료/output/build/verify-layout.cjs`
   - 모든 장과 접힌 항목을 열어 6개 화면 너비에서 텍스트 경계와 구성요소 겹침을 확인합니다.
   - 이미지 안의 SVG도 별도로 열어 실제 글자 경계를 측정합니다. SVG 로딩 성공만으로 글자 배치가 검증된 것은 아닙니다.
   - 긴 한글·영문·기호·여러 줄 설명 회귀 사례를 생성합니다. 검사 결과와 캡처는 `output/validation/`에 저장합니다.
2. `node Projects/P-Harness_교육자료/output/build/verify.cjs`
   - 목차·검색·이미지 확대·반응형·오프라인 동작을 확인합니다.
3. 전체화면·복사 관련 변경이 있으면 로컬 미리보기 서버 실행 후 `verify-interactions.cjs`도 실행합니다.
4. 내장 브라우저를 새로고침하고 변경된 화면을 실제로 확인합니다. 해시 이동만으로는 최신 HTML이 다시 로드되지 않습니다.

자동 검사 후 도식, 긴 제목, 표, 메뉴 캡처와 좁은 화면의 실제 렌더링도 확인합니다. 회귀 사례 SVG는 검증용이며 배포 HTML에는 포함하지 않습니다.

## 읽기 밀도
- 기본 구조는 style.css, 색과 시각 구성은 editorial.css, 단일 화면의 읽기 간격과 설명·캡처 배치는 reading.css에서 관리합니다. 세 파일은 하나의 HTML에 포함되며 별도 버전이나 모드를 만들지 않습니다.
- screen_guide()는 설명과 화면 미리보기를 넓은 화면에서 나란히, 좁은 화면에서 순서대로 배치합니다. 원본 이미지는 확대 창에서 확인합니다.


## 시스템 안내서의 시각 구조
- visuals.py는 표지·화면 지도·장별 의미 도식을 생성합니다. textbook.css는 각 도식의 레이아웃을 정의하며 reading.css 다음에 포함됩니다.
- 그림의 연결 대상은 본문 ID이며 목차·검색과 같은 상세 항목으로 이동합니다. 모든 내부 링크 대상과 모든 하위 목차를 검증합니다.
- 화면 지도는 원본 캡처 위에 CSS 영역 표시를 얹습니다. 이미지 확대에서는 원본이 열립니다.
- 경쟁사 분석 미리보기는 활용 장에 배치합니다. 원래 start-result ID는 기존 직접 링크 호환성을 위해 유지합니다.

## 이미지 번들
- embed_assets.py가 최종 HTML의 이미지를 중복 제거하고 스크린샷을 WebP 품질 85, method 6으로 압축합니다. 입력 캡처 파일은 변경하지 않습니다.
- 본문은 data-asset ID를 참조하고, 문서 마지막 embedded-images JSON에 Base64를 저장합니다. 마지막 로더가 이미지를 연결하며 외부 파일 요청은 없습니다. 확대도 동일한 데이터를 사용합니다.
- 소스 캡처는 FHD로 보존하며 배포 HTML의 이미지는 압축본입니다. SVG 도식은 벡터로 유지합니다.
