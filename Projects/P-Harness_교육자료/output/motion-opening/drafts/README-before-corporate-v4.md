# P-Harness 교육 오프닝 — 15초 개정 시안

`p-harness-opening.html`을 브라우저에서 열고 **소리와 함께 재생**을 누르면 시작합니다. 외부 파일이나 서버 없이 전달할 수 있는 단일 HTML입니다.

P-Harness를 **선택부터 실행, 결과물까지 이어지는 AI 업무 공간**으로 소개합니다. 사내외 정보를 바탕으로 빠르게 조사하고 보고서를 만드는 점은 대표 활용 예로 포함합니다. 모눈종이·반복 배경선은 제거하고 네이비·블루 및 옅은 블루 그라데이션을 적용했습니다.

장면마다 AI 업무 공간 → 다양한 업무 → Model·Skill·MCP → 대표 조사 사례 → 결과물 검토·활용 → 브랜드라는 다른 역할을 맡습니다. 특정 사례가 모든 장면의 메시지를 대체하지 않습니다.

- 15초, 가로 16:9, 1920×1080 기준으로 그리는 JavaScript Canvas 모션그래픽. 26초 초안보다 정지 시간이 짧고 전환·등장이 빠릅니다.
- Paperlogy 3개 굵기 내장. 글자와 문서 도형을 직접 그리며 이미지/영상 파일을 재생하는 방식이 아닙니다.
- 재생·일시정지, 다시 시작, 탐색 막대, 전체화면, 장면별 텍스트 설명.
- 시작 버튼 또는 재생 버튼으로 화면과 소리를 함께 시작합니다. 소리 끄기/켜기가 가능하며, 일시정지 중 소리를 켜면 이어 재생합니다. 종료 후 소리를 켜면 처음부터 재생합니다. 내레이션은 없습니다.
- 160 BPM 일렉트로 팝: 첫 박부터 킥·스네어·베이스, 3초 단위 멜로디 훅과 코드 변주. 긴 피아노 여운을 제거하고 14.25초에 엔딩 타격을 넣었습니다. 15초 스테레오 음원은 HTML 안에 내장되며 컨트롤 옆 막대는 실제 Web Audio 출력 신호를 표시합니다.
- 영상 영역 우클릭으로 전체화면 진입·종료. 전체화면에는 단축키 안내를 띄우지 않으며 일반 화면 아래의 안내는 유지합니다.
- Space 재생·일시정지, 좌우 방향키 5초 이동, M 사운드, F 전체화면. 컨트롤에 초점이 있을 때는 해당 컨트롤의 기본 키보드 동작을 유지합니다.
- 운영체제의 동작 줄이기 설정이 켜져 있으면 마지막 타이틀에서 정지합니다. 재생 버튼으로 직접 시작할 수 있습니다.
- 탭을 떠나면 일시정지하며 자동으로 다시 시작하지 않습니다.

## 편집

`build/opening.template.html`의 `scene0`–`scene5`가 장면, `STARTS`가 전환 시각, `render`가 시간축을 담당합니다. 모든 장면은 절대 시간으로 계산하므로 탐색 막대를 앞으로 또는 뒤로 옮겨도 같은 시각에는 같은 그림을 보여줍니다.

저장소 루트에서 다음 명령으로 최종 파일을 다시 만듭니다.

```powershell
python 'Projects/P-Harness_교육자료/output/motion-opening/build/build.py'
```

폰트 원본은 기존 `Projects/AI코딩교육(기초)/output/assets/`를 사용합니다. 배포되는 HTML에는 이미 내장되어 있습니다.

## 시각 표현 범위

Model·Skill·MCP의 설명은 기존 교육자료를 참고했습니다. 문서 이미지와 연결 도형은 개념을 보여주는 연출입니다. 실제 P-Harness 화면이나 업무 실행 기록, 실적 수치가 아닙니다. 기존 사용자 가이드는 수정하지 않았습니다.

## 검증

2026-09-29 Codex 내장 브라우저에서 6개 장면의 실제 렌더링, 키보드 버튼 활성화, 구간 탐색, 전체화면 진입/종료, 재생 완료, 소리 토글, 동작 줄이기, 390×844 화면을 확인했습니다. 15초 개정본은 시작과 종료 후 재시작에서 AudioContext `running`, 실제 출력 RMS 0.0770 및 0.1204를 확인했습니다. 검증 이미지는 `validation/`에 있습니다.

JavaScript 구문 검사 통과. 폰트 3종 내장, 외부 스크립트/스타일/이미지 참조 없음. 좁은 화면에서 가로 넘침 없음.

남은 검증 범위: 이번 내장 브라우저 세션에서 마우스 자동화 클릭은 상태 변경을 확인하지 못했습니다. 같은 버튼의 Enter 활성화와 키보드 제어는 동작했습니다. 실제 스피커 청취와 다른 브라우저의 로컬 파일 실행은 별도로 확인하지 않았습니다.

## 사운드 교체 및 전체화면 수정 (2026-09-29)

`build/build_audio.py`는 실제 피아노 음색으로 시작·마무리, 넓게 배치한 화음, 짧은 전환음과 스테레오 잔향을 구성합니다. `audio/opening-piano.mp3`를 만든 뒤 `build/build.py`를 실행하면 음악도 단일 HTML에 포함됩니다. 화면·카피·15초 장면 타이밍은 유지했습니다.

음색 출처: [Salamander Grand Piano / Alexander Holm](https://github.com/Tonejs/audio/blob/master/salamander/README), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). 원본 샘플은 `input/motion-audio/salamander/`에 보관했습니다. 개별 음의 피치·음색·길이·배치와 잔향을 편집한 별도 오프닝 믹스입니다. HTML의 접힌 장면 설명에도 출처·라이선스·수정 사실을 표기했습니다.

음원 디코딩 검사: 15.000초, 44.1kHz 스테레오, 최대 피크 -2.27 dBFS, 클리핑 0샘플. 정확한 측정값은 `validation/audio-mix-checks.json`에 기록했습니다. 실제 스피커 청취 평가는 별도입니다.

최신 내장 브라우저 검사: 새 음원 `piano-v2`의 15.000초 디코딩, AudioContext `running`, 출력 RMS 0.0063 / 0.0077을 확인했습니다. 영상 우클릭으로 전체화면 진입·종료와 Esc 종료를 확인했고 전체화면에는 단축키 안내가 없습니다. 일반 화면에는 안내를 유지했습니다. 콘솔 오류·경고는 없었습니다. 새 음원에서 음소거 상태 변경은 자동화로 확인되지 않았으며 기존 제어 코드는 유지했습니다. 세부 결과는 `validation/audio-fullscreen-browser-checks.json`, 화면은 `validation/revision-fullscreen-clean.png`에 기록했습니다.

## 최신 사운드: 강한 비트와 멜로디 (electro-v3)

사용자 피드백 “15초로 짧은 광고 같은 건데 … 비트 강해야 하고 멜로디도 좀 있는 걸로”를 반영했습니다. 이전 피아노 중심 구성은 대체합니다. 첫 박부터 킥·스네어·하이햇·베이스가 진입하며, 3초 멜로디 훅을 D–Bm–G–A–D 코드에 맞춰 변주합니다. 신스와 짧은 피아노 어택을 겹친 멜로디, 장면 전환 악센트, 14.25초의 마지막 타격으로 구성했습니다. 화면·카피·전체화면 조작은 그대로입니다.

`build/build_audio.py`가 `build/build_electro.py`를 실행해 `audio/opening-electro.mp3`를 만듭니다. 이후 `build/build.py`를 실행하면 새 트랙을 내장한 HTML이 생성됩니다. 이전 피아노 버전은 `drafts/piano-v2/`에 보관했습니다. 기존 피아노 샘플 출처·라이선스는 동일하며, 드럼·베이스·신스는 제작 스크립트에서 합성합니다.

검증: JavaScript 구문 통과. 15.000초 / 44.1kHz / 2채널 / 디코딩 후 클리핑 0샘플. `validation/audio-electro-checks.json`에 파형 수치를 기록했습니다. 내장 브라우저에서 `electro-v3`, AudioContext `running`, 출력 RMS 0.0646을 확인했습니다. 실제 스피커 청취 평가는 별도입니다.
