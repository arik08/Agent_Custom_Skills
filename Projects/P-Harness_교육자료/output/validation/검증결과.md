# P-Harness 교육자료 검증 결과

검증일: 2026-09-28

## 배포 산출물
- `../p-harness-guide.html`: 세로형 단일 HTML, 약 1.44 MB.
- 13개 장, 50개 세부 항목, MyHarness 실제 화면 7장, SVG 개념도 2장.
- 가로형 또는 별도 발표 버전 없음. 이미지·CSS·JavaScript 내장, 외부 라이브러리 요청 없음.

## 실제 화면 확보
- 사용자 요청에 따라 MyHarness 로컬 서버를 실행하고, 사용자가 제공한 접근 권한으로 내장 브라우저에서 확인했다.
- 캡처는 모두 실제 MyHarness UI에서 얻은 1920×1080 JPEG 원본이다. 모델·Effort 선택, 확장 목록, 프로젝트 파일 목록, 보고서 Viewer, CSV 첨부 상태를 포함한다.
- 원본은 `../../input/captures/`에 저장했다. 브라우저 캡처 반환 형식이 JPEG여서 확장자와 MIME을 JPEG로 맞췄다.
- 실제 화면의 입력창 아래 모델·Effort 위치를 반영했다. 기존 사용법의 좌측 하단 안내를 그대로 복제하지 않았다.
- 첨부 예시는 교육용 가상 CSV이며 AI에 전송하지 않았다. 캡처 후 직접 입력한 문장과 첨부 표시를 정리했다.
- 등록 목록은 `../../input/captures/skill-menu.txt`에 기록했다. 비밀번호와 인증 정보는 파일에 저장하지 않았다.

## 자동 브라우저 검증

설치된 Playwright와 Chrome으로 실행했다. 결과는 `checks.json`, `interactions.json`에 기록되어 있다.

- 일반 검증 38/38 통과.
- 상호작용 추가 검증 9/9 통과.
- 모든 ID의 유일성, 앵커 대상, 50개 목차 이동, 접힌 본문 공개, 현재 목차 표시, 직접 해시 접근을 확인했다.
- 한글·영문·공백·결과 없음·특수문자 검색을 확인했다. 새로 추가한 장과 세부 항목도 목차와 검색에 자동 반영되는 것을 별도 검사했다.
- 이미지 확대·축소·닫기와 원래 초점 복귀, 요청문 구체화 단계의 전진·후진, 체크리스트 갱신·초기화를 확인했다.
- Chrome에서 실제 Fullscreen API로 우클릭 진입, 재우클릭 해제, 버튼 진입, Esc 종료, 확대 창 안 우클릭을 확인했다. Shift+우클릭은 전체화면을 전환하지 않았다.
- 요청문 복사 결과와 원문이 일치했다. Windows 클립보드의 CRLF는 LF로 정규화하여 비교했다.
- 클립보드 거부를 강제로 발생시켰을 때 원문 선택과 수동 복사 안내를 확인했다.
- 전체화면 거부 시 안내 문구와 실제 상태 표시가 유지되는지 확인했다.
- 1920 / 1440 / 1024 / 768 / 390px 폭에서 문서 가로 넘침이 없었다. 긴 표는 해당 컨테이너 안에서만 가로로 스크롤한다.
- 오프라인 file:// 환경에서 검색과 모든 이미지 9장의 정상 로드를 확인했다.
- 페이지 오류와 콘솔 오류 없음.

## 내장 브라우저 실검증
- 페이지 열기, 화면 확인, MCP 검색 결과, 접힌 심화 항목 검색 후 펼침·이동, 현재 목차 표시, FHD 이미지 확대를 직접 확인했다.
- 내장 브라우저의 전체화면은 호스트 환경에서 즉시 해제되는 상태가 관찰되었다. 이를 일반 브라우저의 실패로 간주하거나 내장 브라우저에서 유지되는 것으로 보고하지 않는다. Chrome에서는 위의 Fullscreen API 진입·해제 검증을 통과했다.
- 원본 캡처와 첫 화면·모바일·요청문·모델 안내·파일 첨부 안내의 렌더링을 시각 검토했다.

## 좌상단 명령어 버튼 우선 안내
- MyHarness 실제 UI에서 좌상단 `/` 버튼의 접근성 이름이 “명령어”임을 확인했다. 명령어 창의 스킬·MCP 항목을 각각 펼쳐 이름·설명·활성 표시를 읽었다. 도구의 활성 설정은 변경하지 않았다.
- 첫 업무 안내, Skill 장, MCP 장, 단축키 참고를 같은 흐름으로 수정했다. `$`와 입력창 호출 버튼은 특정 도구 지정의 보조 방법으로 배치하고 `@`는 파일 연결로 구분했다.
- 세 장의 실제 FHD 캡처를 추가했다. 파일 해상도는 각각 1920×1080이며 원본 픽셀은 유지했다. 본문은 해당 영역을 CSS로 확대하고 이미지 확대 창에서는 전체 원본을 제공한다.
- 13장·53개 항목: 1920, 1440, 1280, 1024, 768, 390px 레이아웃 검사 오류 0. 기존 기능 검사 38/38 및 본문 이미지 12개 오프라인 로드 확인.
- 내장 브라우저에서 새 목차 이동, Skill·MCP 우선 경로, 명령어 버튼 이미지 확대 시 원본 1920×1080을 확인했다. 최종 화면: slash-first-guide-iab.jpg.
- 사내 MCP의 목록·활성 표시를 실제 조회 성공으로 단정하지 않도록 안내를 정리했다. P-Harness 운영 환경의 동작과 사내 시스템 조회는 별도 미검증이다.


## 정보 밀도 개선 검증
- 13장·53개 항목의 본문을 유지하고, 제목·표·단계·카드·안내 박스의 공통 간격을 줄였다. Skill·MCP 조회, 보고서 구성, 파일 확인은 공통 screen_guide 구조로 설명과 캡처를 나란히 배치한다. 모바일에서는 한 열로 표시한다.
- 본문 기본 글자 크기는 데스크톱 18px, 모바일 16px로 유지했다. 수정 전후 본문 문자 구성을 대조해 재배치 외 내용 누락이 없음을 확인했다.
