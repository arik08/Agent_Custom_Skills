# AI 기반 Vibe Coding (초급) 교육

> 말로 요청하고, 실행 결과를 확인하며, 내 업무에 필요한 프로그램 만들기

- 일정: 9/29 (화) 16:00 ~ 17:00 (총 60분)
- 대상: AI 코딩을 처음 접하거나, 업무에 어떻게 활용할지 알고 싶은 입문자
- 진행 방식: 개념 설명과 강사 시연 중심. 설치 안내는 별도 자료로 제공
- 교육 목표: Coding Agent의 역할을 이해하고, 원하는 작업을 요청·수정·확인하는 기본 흐름과 사내 AI 활용의 시작점을 익힌다.

## 1. Vibe Coding이란? 왜 배워야 할까? (8분 · 16:00~16:08)

- 자연어로 원하는 동작을 설명하고, AI와 함께 코드를 만들고 고쳐 나가는 방식
- AI를 단순 챗봇으로 사용하는 것과 무엇이 다른가?
  - 챗봇에게 수정 방법을 묻는 경험에서, Agent가 작업 파일을 찾아 수정하고 실행 결과까지 확인하는 경험으로 확장
- 업무에서 어디에 활용할 수 있을까?
  - 반복 작업 자동화, 자료 정리, 간단한 웹 화면과 업무 도구 제작
- 짧은 도입 시연: 요청 한 번으로 기존 프로그램의 한 부분이 바뀌는 모습 보여주기

## 2. AI 코딩에 필요한 최소한의 기초 (10분 · 16:08~16:18)

- Coding Agent는 어떻게 일하는가?
  - 허용된 범위에서 파일을 읽고 수정하며, 터미널 명령으로 프로그램을 실행하는 작업 흐름
  - CLI란? 텍스트 명령으로 컴퓨터에 작업을 지시하는 방식
- 무엇을 어떻게 요청하면 될까?
  - 하고 싶은 일을 말로 설명하는 것부터 시작
  - 어떤 자료를 넣고, 무엇을 처리하고, 어떤 결과를 원하는지 구체적으로 전달
- 언어와 프로그램 구조의 기본 개념
  - Python: 데이터 처리와 업무 자동화 예시
  - HTML/CSS/JavaScript: 웹 화면의 구조·모양·동작
  - 프론트엔드와 백엔드: 화면에서 요청하고, 뒤에서 처리해 결과를 돌려주는 관계
- LLM 모델과 추론 노력의 의미
  - 모델별 특징과 작업에 맞는 선택 기준
  - 추론 노력 설정에 따른 응답 시간과 문제 해결 방식의 차이
  - 실제 교육 환경에서 제공되는 설정을 기준으로 설명

## 3. AI 코딩 도구와 시작 환경 (10분 · 16:18~16:28)

- 도구를 사용하는 세 가지 방식: 전용 앱, VS Code 확장, CLI
  - Codex App, VS Code + Codex 확장, Codex CLI를 중심으로 소개
  - Cline, Kilo Code, Claude Code 등 다른 선택지는 간단히 소개
- 강의 기준 환경 안내
  - Python, VS Code, Codex 확장
  - Python 확장, Korean Language Pack, 색상 테마 등 편의 설정
  - Node.js와 Git은 선택한 설치 방식과 작업에 따라 필요 여부를 구분해 안내
- 회사 환경에서의 시작 방법
  - 원안에 제시된 사내 전용 앱 사용 제약을 반영해 VS Code 및 CLI 경로 설명
  - Codex CLI 설치·실행 흐름 소개
- 실행 권한과 승인 설정
  - Full Access의 의미와 승인 요청에 미치는 영향 설명
- 설치 명령과 다운로드 링크는 별도 안내 자료에 제공

## 4. Vibe Coding 시연: 요청에서 수정까지 (15분 · 16:28~16:43)

- 작은 업무 도구 하나를 예제로 전체 흐름 시연
  1. 목표 설명: 무엇을 만들고 싶은지, 입력과 출력은 무엇인지 전달
  2. 생성 및 실행: Agent가 파일을 만들고 실행하는 과정 확인
  3. 결과 확인: 원하는 동작과 실제 결과 비교
  4. 추가 수정: 화면이나 기능 변경을 요청하고 다시 확인
- 오류가 나거나 원하는 결과가 나오지 않을 때의 요청 방법
  - 오류 메시지, 기대한 동작, 실제 동작을 함께 전달
- 반복해서 적용할 작업 규칙은 AGENTS.md에 정리
  - 폴더 구조, 실행 방법, 결과 확인 방법 등 재사용할 지침 저장
  - 직접 작성하는 대신 Agent에게 정리와 갱신을 요청하는 모습 시연

## 5. 사내에서 사용할 AI 프로그램의 시작점 (12분 · 16:43~16:55)

- AI로 코드를 만드는 것과, 만든 프로그램에서 AI를 호출하는 것의 차이
- API와 API Key의 개념
  - 프로그램이 AI 기능을 요청하는 연결 방식과 이를 사용하기 위한 인증 정보
- P-GPT API 신청 방법과 사용 준비 안내
- 사내 AI 프로그램의 기본 흐름 설명
  - 사용자 입력 → 프로그램의 P-GPT API 호출 → 응답 처리 → 결과 표시
- 앞서 만든 예제에 AI 기능을 붙이는 과정을 설명하거나 준비된 예제로 시연

## 6. 마무리 및 질의응답 (5분 · 16:55~17:00)

- 처음부터 모든 문법과 도구를 외울 필요는 없다.
- 원하는 결과를 설명하고, 실행해 보고, 부족한 부분을 고치는 습관이 중요하다.
- 모르는 용어나 오류를 만났을 때 AI에게 설명을 요청하고 직접 확인하며 배운다.
- 교육 후 첫 과제 제안: 내 업무에서 반복하는 작은 작업 하나를 골라 자동화해 보기
- 질의응답

- 시연이 지연될 때 활용할 단계별 결과 화면과 준비된 실행 결과
