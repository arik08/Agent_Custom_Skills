챗봇의 답변을 직접 적용하기

파일 연결 없이, 코드 답변만 받는 상황

사람의 작업

미리보기·착지 가이드·줄 삭제 효과를 게임에 추가하기

1. 챗봇 · 사람이 코드 조각을 연결

요청 → 세 파일의 코드 답변 → 복사 → 화면과 스타일 적용 → 게임 로직의 연결 위치 찾기 → 함수 연결 → 실행 확인

index.html  → 다음 블록을 표시할 공간
style.css   → 미리보기와 효과의 스타일
tetris.js   → 착지 계산 · 다음 블록 그리기 · 줄 삭제 효과

함수를 붙여 넣는 것만으로는 부족합니다. 게임이 그 함수를 실행하는 위치까지 사람이 연결해야 합니다.

2. 코딩 에이전트 · 파일과 실행 흐름을 함께 수정

같은 요청 → 세 파일과 관련 함수 확인 → 파일 수정 및 실행 위치 연결 → 게임에서 결과 확인

실행 결과: 다음 블록이 보이고, 실제 충돌 위치에 착지 윤곽이 표시되며, 줄 삭제에 빛과 점수 효과가 붙습니다. 사람은 원하는 기능인지, 동작과 표현이 적절한지 판단합니다.
