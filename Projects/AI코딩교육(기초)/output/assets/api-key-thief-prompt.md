생성 방식: 내장 image_gen 도구

Use case: illustration-story. Create a humorous single-panel educational cartoon illustration for a Korean beginner coding presentation. Landscape 3:2 composition, pale icy blue background, bold clean navy ink, soft blue and yellow colors, coral accents. A comically sneaky masked cartoon thief holds a giant gold key labeled "API KEY" and gleefully presses a button on an AI robot vending machine. Gold coins stream from a shocked programmer’s nearly empty wallet into the machine as the robot spits out a ridiculously long paper receipt. The programmer has an exaggerated shocked expression and turned-out empty pockets. Visual meaning: someone who steals your API key can consume your paid AI credits. Friendly, funny, expressive, polished editorial comic, large readable shapes, no violence, no real credentials, no brands. Only text allowed: "API KEY" on key, "AI" on machine, "0" on a small balance display. No speech bubbles, no extra text, keep all subjects fully in frame.
