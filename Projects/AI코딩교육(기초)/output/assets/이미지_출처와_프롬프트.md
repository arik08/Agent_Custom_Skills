# 강의 삽화

현재 발표 자료는 후속 수정본 `workshop-illustrations-posco.png`를 사용합니다. 남성 포스코 사무직 직원과 블루 테마의 편집 프롬프트는 `포스코_테마.md`에 기록했습니다. 아래는 최초 버전의 제작 기록입니다.

- 파일: `workshop-illustrations.png`
- 방식: 내장 imagegen 도구로 신규 생성. 외부 사진·제품 UI 스크린샷이 아님.
- 1536×1024 시트의 4개 영역을 CSS 배경 위치로 사용함. 원본 이미지는 수정하지 않음.
- 용도: 업무 설명, 프로그램 제작, 결과 검증, 사내 API 연결의 개념 설명.
- HTML에는 원본 이미지 데이터를 포함하므로 별도 그림 파일 없이 열 수 있음.
