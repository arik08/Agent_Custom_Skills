## 제작 소스

최신 발표자료 HTML이 현재 배포의 기준 파일입니다. `build/`에는 동작 소스와 검증 스크립트, `assets/`에는 그림 원본이 있습니다. `build/build.py`는 이전 제작 단계의 빌더이므로 최신 HTML 전체를 재생성하는 용도로 사용하지 않습니다.

`vercel/index.html`은 최신 HTML의 배포용 복사본입니다. 재배포할 때 이 폴더에서 다음 명령을 실행합니다. 기존 Vercel 프로젝트 연결 및 로그인이 필요합니다.

```powershell
Copy-Item -LiteralPath './260929_경영기획DX추진TF팀_AI_CODING_기초교육.html' -Destination './vercel/index.html'
vercel --cwd ./vercel --prod --yes --scope arik1988-1398s-projects
```

기획안2 표지의 원본은 `Projects/hq-ax-diorama/output/hq-ax-diorama.html`입니다. 기존 슬라이드 빌드 후 `node build/embed-diorama.mjs`를 실행하면 최신 디오라마를 다시 포함합니다. 첫 장을 떠나면 멈추고 돌아오면 재개합니다. 후처리는 반복 실행할 수 있습니다.

## 기존 강사 시연 예제

`demo/`에서 `python summarize.py`를 실행하고 생성된 `report.html`을 브라우저로 엽니다. Python 표준 라이브러리만 사용하며 외부 AI 호출은 없습니다. 전체 6건·완료 2건·미완료 4건이 기준입니다.

P-GPT 신청 경로, 권한, 인증 및 사내 네트워크 연결은 실제 사용 환경에서 별도 확인해야 합니다. 교육용 시연은 실제 사내 연동 성공을 의미하지 않습니다.
