# AI 기반 Vibe Coding · 초급 교육 자료

## 열기

`AI코딩교육_기초.html`을 Chrome 또는 Edge에서 엽니다. 설치나 서버 없이 파일 하나로 동작합니다. 그림·Paperlogy 글꼴이 내장되어 있으며 공식 문서 링크를 열 때만 인터넷이 필요합니다.

- HTML: 본문 29장 + 참고 부록 3장
- PDF: 단계 노출을 모두 펼친 32페이지 백업
- `교육_기획안_발표용.md`: 60분 시간표와 정리한 교육 내용
- `발표자_진행노트.md`: 장별 시간, 설명 포인트, 시연 전환, 사내 확인 사항
- `demo/`: 가상 데이터와 실행 가능한 Python → HTML 예제
- `validation/`: 검사 결과와 전체 슬라이드 미리보기

## 발표 조작

- `→`, `Space`, 화면 빈 곳 클릭: 다음 단계 또는 다음 장
- `←`: 이전 단계 또는 이전 장
- `↑` / `↓`: 장 단위 이동
- `Home` / `End`: 첫 장 / 마지막 장
- 숫자를 연속 입력: 해당 장 이동 (예: 17)
- `F`: 전체화면, `?`: 도움말
- `M`: 목차, `N`: 현재 장 발표자 노트, `Esc`: 닫기
- 터치 화면에서는 좌우 스와이프

컨트롤·링크가 있는 장은 빈 곳 클릭으로 넘어가지 않습니다. 하단 화살표나 키보드를 사용하세요. 발표자 노트는 투사 화면에도 보이므로 강사 참고용으로 열어 주세요. 휴대폰은 가로 방향을 권장합니다.

## 강사 시연 예제

PowerShell에서 `demo` 폴더를 열고 다음을 실행합니다.

```powershell
python summarize.py
```

같은 폴더에 생성되는 `report.html`을 브라우저로 엽니다. 입력·출력 경로도 지정할 수 있습니다.

```powershell
python summarize.py tasks.csv report.html
```

Python 표준 라이브러리만 사용하며 외부 AI 호출은 없습니다. 전체 6건·완료 2건·미완료 4건이 기준입니다. 준비된 완성본이므로 강의에서는 별도 교육용 복사본으로 새 기능을 요청해 보는 방식이 적합합니다.

## 확인이 남은 사내 항목

P-GPT 신청 링크, 승인 담당자, 인증 방식, 엔드포인트, 모델, Responses 지원 여부, 사내 CA·프록시 설정은 제공되지 않았습니다. 관련 슬라이드는 준비 항목과 연결 개념을 설명합니다. 실제 사내 연동 성공을 주장하는 자료가 아니며, 강의 전에 사내 안내를 반영해야 합니다.

## 제작 및 수정

`slidestyle-html` 골격과 감사 스크립트를 사용했습니다. `frontend-design`이라는 이름의 보조 스킬은 설치되어 있지 않아, 별도 디자인 스킬에 의존하지 않고 슬라이드 스킬의 조판·무대·검증 지침을 적용했습니다.

`build/build_deck.py`는 HTML과 발표자 노트를 다시 만듭니다. 삽화·글꼴은 `assets/`를 사용하고, 자산이 이미 있으면 다운로드하지 않습니다. PDF 재생성:

```powershell
python build/export_pdf.py AI코딩교육_기초.html
```

이미지 생성 방식과 프롬프트는 `assets/이미지_출처와_프롬프트.md`에 기록했습니다. HTML 한 파일을 전달해도 발표할 수 있습니다.
