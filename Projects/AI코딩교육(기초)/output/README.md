HTML은 그림과 글꼴을 내장하여 단일 파일로 실행됩니다. 기초·인터랙티브 v2의 이전 배포 HTML/PDF는 현재 폴더에서 정리했으며 Git 이력에 남아 있습니다. 기존 기획안과 제작 자료는 참고용으로 유지합니다.

## 제작 소스

v3는 `build/build.py`로 HTML을 생성합니다. 상세 동작 검사와 제작 자료는 해당 폴더의 `build/`, `assets/`, `validation/`에 있습니다.

기획안2 표지의 원본은 `Projects/hq-ax-diorama/output/hq-ax-diorama.html`입니다. 기존 슬라이드 빌드 후 `node build/embed-diorama.mjs`를 실행하면 최신 디오라마를 다시 포함합니다. 첫 장을 떠나면 멈추고 돌아오면 재개합니다. 후처리는 반복 실행할 수 있습니다.

## 기존 강사 시연 예제

`demo/`에서 `python summarize.py`를 실행하고 생성된 `report.html`을 브라우저로 엽니다. Python 표준 라이브러리만 사용하며 외부 AI 호출은 없습니다. 전체 6건·완료 2건·미완료 4건이 기준입니다.

P-GPT 신청 경로, 권한, 인증 및 사내 네트워크 연결은 실제 사용 환경에서 별도 확인해야 합니다. 교육용 시연은 실제 사내 연동 성공을 의미하지 않습니다.
