# 체험과 안목 v3 검증

## 결과

- 발표 25장, 용어 해설 24개. 60분 진행안과 후반 10분 제작 요청문 제공.
- 브라우저 기능 검사 78개 통과. 별도 준비본 검사 8개 통과.
- Edge/Chromium에서 실행. 브라우저 실행 오류 0건, 외부 HTTP 요청 0건.
- 네트워크 오프라인 상태에서 단일 HTML의 폰트·그림·상호작용 확인.
- 생성 그림 4종 모두 WebP이며 실제 alpha 채널과 완전 투명 픽셀을 확인. HTML에는 base64 내장.
- 발표 HTML 약 1.71MB. 기존 발표 파일은 편집하지 않고 별도 폴더에 제작.
- 기존 slidestyle 감사 스크립트 통과: 한글 조판, 무대 비율, 레이아웃, 컨트롤 구역 확인.
- PDF 31쪽: 발표 25쪽 + 용어 해설 6쪽. 빈 페이지 없음, 24개 용어 해설 포함 확인.

## 확인한 기능

테트리스 생성 과정 재현과 점수, 색상·점수판·다음 블록·착지 가이드·줄 삭제 효과의 단계별 개선, 초기화, 파일 탐색, 실행 재현, HTML/CSS/JavaScript 단계 비교, 로컬·서버 요청 경로, GUI 정보 순서·간격·버튼 이름 변경, 정상·경계·빈 값·잘못된 값·범위 밖 점수, 구체적 요청 비교, 변경 이력 비교, 실제 제작 타이머의 시작·정지·초기화, 순위 정렬, 동점 공동 순위, 입력 HTML 이스케이프, API 정상·실패·빈 입력 재현, 준비 환경 전환을 확인했습니다.

용어 호버, 포인터를 설명 패널로 옮겼을 때 유지, 키보드 포커스, 클릭 고정, Escape 닫기, 장 이동 시 닫기, 화면 경계 안 배치를 확인했습니다. 입력란의 키 조작, 수정키, 큰 휠 입력의 한 장 이동, 작은 휠 누적, 방향 반전, 빠른 키 이동, 해시 진입, 처음·마지막 장 제한, 우클릭 전체화면 진입과 F 해제, 전체화면 실패 시 오류 처리도 확인했습니다.

16:9, 16:10, 4:3, 초광폭, 세로형 창에서 16:9 무대가 잘리지 않고 맞춰지는지 확인했습니다. 모든 장의 실제 스크린샷과 전체 썸네일을 확인했고, 감소된 모션 설정 및 애니메이션 중 즉시 이동을 검사했습니다.

## 발견 후 수정한 사항

- 표지 그림의 투명 여백이 안전 영역을 넘는 배치를 줄였습니다.
- 처리 실험 장의 하단 설명이 연결 문장과 가까워져 본문 높이를 줄였습니다.
- 구조 삽화는 개별 부분의 표시 영역을 조정해 해당 이름 바로 위에 배치했습니다. 첫 조정에서 이웃 그림이 섞인 것을 실제 화면에서 확인하고 잘림 영역을 수정했습니다.
- 인라인 무대 배율이 PDF에 적용되지 않도록 인쇄 스타일을 보강했습니다.
- hidden 요소와 별 버튼의 CSS 충돌을 방지했습니다.
- 한글 예시가 모노 서체를 상속하지 않도록 조정했습니다.

## 미검증 및 구분

- 실제 외부 코딩 에이전트의 10분 내 생성 완료 여부는 검증하지 않았습니다. 준비본은 실제 생성 결과와 구분합니다.
- 실제 P-GPT 연결, 사내 신청·인증·모델·네트워크 환경은 검증하지 않았습니다. 해당 구간은 규칙 기반 재현입니다.
- 실제 행사장 프로젝터, 터치 기기와 화면 읽기 보조기술은 검증하지 않았습니다. 클릭·포커스·화면 크기 동작은 데스크톱 브라우저에서 검사했습니다.
- PDF는 정적 백업이며 게임과 상호작용은 HTML에서 실행됩니다. 대표 상태와 용어 부록을 제공합니다.

상세 기록: verification.json, demo-verification.json, image-alpha.json, pdf-check.json, skill-audit.json 및 각 장 스크린샷.

## 테트리스 체험 갱신

- 첫 생성부터 빠른 자동 플레이(기본 낙하 간격 40ms), 단색 첫 버전에서 3단계 개선. 게임 상태를 유지하며 누적 반영.
- VS Code 유사 파일 탐색기·편집기·변경 내용·터미널·Codex 패널을 연동. 실제 AI 호출은 교육용 재현으로 표시.
- 테트리스 엔진 및 체험 흐름 별도 검사 42개 통과: 자동 배치 150개에서 58줄 삭제, 여러 줄 삭제, 충돌, 종료·초기화, 자동·직접 조작, 개선 연속성, 비활성 장 정지, 화면 배율 확인.
- IDE 내부 그리드 행 높이를 제한해 입력란 포커스 시 상단 메뉴가 밀리는 현상을 수정. 요청문 입력란 높이도 조정.
- 상세 결과와 전후 화면: tetris/verification.json 및 tetris/*.png.

- PDF 전체 슬라이드의 세로 배치 규칙을 명시하여 비활성 슬라이드의 인쇄 배치를 수정하고 31쪽을 다시 렌더링했습니다.
