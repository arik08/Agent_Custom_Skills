## 디자인과 제작

- 업무 메모 한 건을 반복해 사용하며 화면, 처리 규칙, 폴더, 터미널, 제작, API로 연결했다.
- 포스코 블루 계열과 Paperlogy 내장 폰트를 유지하고, 내장 imagegen으로 협업·프로그램 구조·터미널 실행·가상환경 장면 4종을 새로 생성했다. 공식 VS Code·Python·Node.js·Git 아이콘, 직접 작성한 SVG 도식, 기존 인증 키 자산을 함께 사용했다. [자산 원본·출처·생성 프롬프트](../../assets/visual-plan2/README.md).
- 게임과 업무 정리는 로컬 코드로 실제 동작한다. 준비된 예제와 AI 실시간 생성, 규칙 기반 처리와 모델 호출을 구분했다.
- HTML 하나에 CSS·JavaScript·폰트·이미지를 내장했다. 공식 설치 링크를 여는 경우에만 외부 웹사이트가 필요하다.
- 제작 소스: `../../build/build_plan2.py`, `../../build/plan2.css`, `../../build/plan2.js`, `../../build/visual_plan2.py`, `../../build/visual-plan2.css`, `../../build/visual-plan2.js`.

## 실행한 검사

- 시각화 개편 후 최종 HTML에서 `audit.js` 31장 및 `check_plan2.js` 52개 검사를 다시 실행하여 모두 통과했다.
- 새 자산을 포함한 HTML 이미지 10개 요소 모두 로딩 성공. SVG·이미지·캔버스를 포함한 장은 30장이고 나머지 장은 CSS 기반 비교 도식이다.
- 비활성 장의 SVG 애니메이션 정지와 `prefers-reduced-motion: reduce`에서 전체 SVG 애니메이션 정지를 확인했다.
- 생성 이미지 4개는 실제 RGBA 투명 채널을 확인했다. 터미널·가상환경 이미지의 컨테이너 넘침을 수정한 뒤 전체 장 검사 통과.
- 최종 PDF 37쪽 재생성 및 PNG 렌더링 완료. 전체 개요와 개편한 핵심 장을 시각 검토했다.
- 아래 5개 화면 비율·전체화면·터치 검사는 개편 이전 공통 런타임에 대한 검사다. 개편 후에는 최종 화면에서 전체 장 레이아웃·52개 기능·자산·모션 검사를 재실행했다.

- 슬라이드 스킬의 `audit.js`: 31장 통과. 논리 무대 크기 1920×1080, 콘텐츠 넘침, 한글 조판, 기본 탐색 계약을 확인했다.
- `check_plan2.js`: 52개 검사 통과. 필수 이동 키, 연속·반복 입력, 경계, 휠 누적·대량 delta·단위·방향 반전, 입력란 충돌 방지, 정상·누락·빈 값·신규 이름·다른 업무·전각 콜론·HTML 문자열 입력, 구성 전환, 수정 전후, 설치 도구 선택, 펼침 설명, 툴팁과 진행 표시를 포함한다.
- 화면 비율: 1600×900, 1440×900, 1200×900, 2100×900, 720×1280에서 무대가 화면 안에 들어오고 16:9 비율을 유지하며 진행 표시가 보이는 것을 확인했다.
- 실제 브라우저 키 입력으로 전체화면 진입, 재입력 해제, Escape 해제를 확인했다. API 거부 상황을 일시적으로 대체한 검사에서도 현재 장을 유지했다. 대체 설정은 복구했다.
- 감소된 모션 환경에서 장 진입 애니메이션이 생기지 않는 것을 확인했다. 터치 툴팁 열기·닫기는 합성 PointerEvent로 확인했다.
- 해시 직접 이동과 진행 번호 동기화를 확인했다.
- 브라우저에서 표지, 게임, 화면 구성, 구조도와 열린 툴팁, Q&A를 직접 시각 확인했다.
- PDF 37쪽을 PNG로 렌더링하고 전 페이지 개요를 검토했다. 빈 페이지 0쪽. Responses API의 펼침 설명과 기한 누락 처리 결과가 PDF에 포함됨을 텍스트로도 확인했다.

## 발견해 수정한 사항

- 표지 하단의 콘텐츠 경계와 컨테이너 높이를 정리했다.
- 제목 한글 자간을 완화하고, 터미널 설명의 한글이 모노 서체 규칙을 물려받지 않도록 수정했다.
- 시간표 내부의 용어 툴팁 요소가 블록으로 바뀌어 불필요하게 줄바꿈되던 부분을 수정했다.
- 투명 이미지 스프라이트의 인접 셀 일부가 보이지 않도록 표시 범위를 조정했다.
- 선택되지 않은 개발도구에도 충분한 대비를 유지하도록 투명도 처리를 제거했다.
- 이전 자료에서 재사용한 용어 해설 중 CSV·공개 API 코드 등 이번 덱에 없는 예제를 언급하던 문구를 현재 내용에 맞췄다.

## 검증의 범위

- 내장 브라우저 `iab`는 사용 불가 응답을 반환하여 Chrome에서 확인했다. Aside는 사용하지 않았다.
- 실제 터치 기기, 물리 트랙패드, 행사장 화면, 사내 브라우저 환경, OS 클립보드 권한별 실동작은 미검증이다. 휠·터치의 프로그램 이벤트 경로를 검사한 사실과 구분한다.
- P-GPT 실제 호출, 신청 절차, 모델 지원, 사내 인증서·검색 기능은 검증하지 않았다. 교육자료에서 확인할 항목으로 명시했다.
- 브라우저 로그에는 기존 Adobe 확장 스크립트 오류와 확장 메시지 채널 오류가 관찰됐다. 이를 덱 자체의 검사 통과와 구분한다.
- API 연결 및 게임 자동 플레이는 모델이 실시간으로 생성 중이라는 증거가 아니다. 덱은 준비된 교육용 산출물이다.
