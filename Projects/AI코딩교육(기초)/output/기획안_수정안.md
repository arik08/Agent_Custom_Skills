## Vibe Coding은 무엇이고, 왜 필요한가? 

### 용어는 외우지 않아도 됩니다.
- 오늘은 ‘AI에게 업무를 설명하는 방법’, ‘만든 결과를 확인하는 방법’, ‘직접 써보기 위한 도구와 설치 방법’ 세 가지만 가져가시면 됩니다.
- 대략적인 흐름만 알고, 궁금한 내용은 발표자료를 보거나 AI에게 물어보면 됨.

### 과거 IT 개발은 전문 인력들에 의존하는 "그들만의 리그". 그러나 이제는 상황이 바뀌어, 도메인 전문가도 개발에 깊게 관여해야 시너지가 난다.
- AI는 범용성이 매우 높고, 성능이 빠르게 좋아지며 그 유용성이 급격히 증가하고 있는 상황
- 범용 AI는 우리 회사의 고유 업무에 대한 이해가 없기 때문에 이를 가르쳐줄 사람이 필요
- 회사 도메인 지식을 잘 아는 사람이 직접 개발을 하거나 참여를 해야 가장 높은 완성도를 지님

### AI의 Coding 성능 개선에 따른 프로그래밍 방식의 변화
- 초창기(24~25년)에는 사람이 코딩을 하되 AI가 도와주는 느낌이었음. AI 단독으로는 에러가 많이 발생해서 

### AI를 단순 챗봇으로 사용하는 것과 Coding Agent로 쓰는 게 무엇이 다른가?
- 챗봇은 조언만 해줄 수 있지만 Coding Agent는 사용자의 컴퓨터를 직접 제어하여, 컴퓨터로 할 수 있는 모든 걸 대신할 수 있다.
- 수정할 코드를 알려주는 것뿐만 아니라 스스로 해당 파일을 직접 찾아서 그 특정 부분만 고쳐준다. (매우 중요한 포인트)
- 이를 통해 사용자가 프로그램 코드에 직접 관여하지 않고도 AI와 자연스러운 대화를 통해 프로그램 제작이 가능해진다.

### 관심을 끌기 위한 짧은 게임 시연 (Auto Play가 가능한 HTML 테트리스 등)
- 초반에는 잠시 보여주고, 실제 제작 과정은 뒤의 프로그램 제작 시연에서 설명.
 
## AI 프로그래밍에 필요한 기초 개념 이해 
 
### 기본개념: Backend(Python), Frontend(HTML/CSS/JS) 개념 설명, 라이브러리 & 가상환경, API(Application Programming Interface), Terminal(CMD, Powershell, Bash 등), Git & Github, 환경변수, 마크다운(MD: Markdown), AGENTS.md
- Backend는 비교적 답이 명확하여 AI가 잘 해주지만 Frontend는 취향의 문제라 개발자 관여도가 높음 
- 사람 ↔ 프론트엔드(GUI 화면) ↔〔API〕↔ 백엔드 ↔ DB 
- 웹 기반 응용 프로그램 제작이 대세 (플랫폼에 구애받지 않고, 업데이트 불필요. 과거에는 설치형 중심) 

### LLM 모델별 특징(GPT-5.6-Sol, Terra, Luna) : 문제점을 찾거나 
- 추론 노력 (Low, Medium, High, xHigh, Max, Ultra)
    - AI 성능비교 사이트 추천 (https://artificialanalysis.ai/) 
- "Coding Agent는 여러분의 컴퓨터를 제어할 수 있다. (Terminal 기반)"
    - cd.., dir, ipconfig, cls, 마우스커서 움직이는 예시 보여주기

### "생각하는 모든 것을 AI에게 물어보거나 시키면, 알아서 해준다"
- "... 는 어떻게 하는거야?"
- "... 저 스킬은 내가 준 링크에 있으니 참고해서 이 프로젝트에 설치해줘"
- 과거에는 Google 검색을 통해 해결했지만 이제는 AI에게 물어보면 알려주고, 실행까지 해준다.

## Vibe Coding을 통한 프로그램 제작 시연

- 개발화면 설명 (VSCode 기준): 좌측(파일 구조), 중앙(코드), 하단(터미널), 우측 사이드바(코딩 에이전트 Extension)
- Python 프로그램 제작, HTML 기반 프로그램 제작 시연
- 일단 간단히 시켜보기 → 실행해서 결과 확인 → 불편하거나 원하는 부분을 말로 수정하기. 요청 양식을 외우기보다 경험으로 익히기.
- 컴퓨터 제어 (가능다면) 
- 반복되는 작업은 AGENTS.md에 저장 (직접 쓸 필요는 없고, Agent에게 요청하기) 
- 만든 프로그램을 실행하는 법 (HTML 같이 그냥 눌러도 되는 경우도 있지만 명령어로 실행해야 하는 경우도 많음)
- 만든 프로그램을 다른 컴퓨터에서 사용할 수 있게 하는 법 (의존성 패키지 설치 기능 추가 필요)
