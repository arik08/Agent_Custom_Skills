## Vibe Coding이란? 왜 배워야 하는가? 

- 과거 IT 개발은 전문 인력들에 의존하는 "그들만의 리그" 
- AI는 범용성이 매우 높고 성능이 매우 빠르게 좋아지며 그 유용성이 빠르게 좋아지는 상태
- 회사 업무를 AI로 처리하기 위해서는 그 도메인 지식을 잘 아는 사람이 직접 개발에 참여해야 시너지 극대화

- AI를 단순 챗봇으로 사용하는 것과 무엇이 다른가?
    - 사용자의 컴퓨터를 직접 제어할 수 있다.
    - 수정할 코드를 알려주는 것뿐만 아니라 스스로 해당 파일을 직접 찾아서 그 특정 부분만 고치쳐준다. (중요)
- 간단한 AI Coding Agent 사용모습 시연

## AI 프로그래밍 관련 필요한 개념 이해 

- 기본개념: Backend(Python), Frontend(HTML/CSS/JS) 개념 설명, API(Application Programming Interface), 
           Terminal(CMD, Powershell, Bash 등), Git & Github
    - Backend는 비교적 답이 명확하여 AI가 잘 해주지만 Frontend는 취향의 문제라 개발자 관여도가 높음
- 사람 ↔ 프론트엔드(GUI 화면) ↔〔API〕↔ 백엔드 ↔ DB
    - Backend ↔ Frontend 연결은 API를 통해 HTTP 통신으로 이루어짐

- LLM 모델별 특징, 추론 노력 (Low, Medium, High, xHigh, Max, Ultra)
    - AI 성능비교 사이트 추천 (https://artificialanalysis.ai/) 
- "Coding Agent는 여러분의 컴퓨터를 제어할 수 있다. (CLI 기반)"
    - 파일 조회, 실행, 마우스커서 움직이는 예시 보여주기

- "생각하는 모든 것을 AI에게 물어보거나 시키면 된다"
    - "... 는 어떻게 하는거야?"
    - "... 주소 참고해서 이 프로젝트에 설치해줘"
    - 과거에는 Google 검색을 통해 해결했지만 이제는 AI에게 물어보면 알려주고, 실행까지 해준다.
