## 2026-09-20 완전 초보자용 체험 중심 별도 버전

- 후반 실제 코딩 에이전트 제작 시연은 간단한 기능으로 10분 이내 진행한다. 요청문, 정상/예외 입력, 중간·완성 예제를 준비한다.

- 새 생성 삽화, 포스코 계열 블루/밝은 바탕, 내장 폰트. 어려운 구조는 평면·실제 화면 중심으로 설명한다.
- 추가 명시: 모든 생성 그림은 실제 투명 배경으로 만들고 WebP로 변환해 base64로 단일 HTML에 내장한다. 사용자는 제공된 생성 도구를 gpt-image-2.5라고 확인하며 모델 구분 논의를 멈추고 제작을 진행하도록 요청했다.
