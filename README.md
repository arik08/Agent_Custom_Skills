# Agent Custom Skills

이 프로젝트는 `Skills/`에 있는 스킬을 개량하고, 그 스킬을 사용해 문서와 다양한 산출물을 만드는 작업 공간입니다.

## 폴더 구조

```text
Agent_Custom_Skills/
├── AGENTS.md
├── README.md
├── Skills/                  # 재사용하는 스킬과 관련 리소스
└── Projects/
    └── 주제명/              # 새로운 주제마다 별도 폴더 생성
        ├── input/           # 사용자가 제공한 정보와 원본 자료
        └── output/          # 스킬을 사용해 생성한 파일
```

실제 최상위 폴더 이름은 `Skills/`, `Projects/`를 사용합니다.

## 운영 원칙

- **스킬 개량:** 스킬의 지침, 템플릿, 스크립트 등 재사용할 개선 사항은 `Skills/<스킬명>/`에 반영합니다.
- **새로운 주제:** 새로운 문서 제작 주제를 요청받으면 `Projects/<주제명>/`과 그 안의 `input/`, `output/`을 먼저 생성합니다. 폴더 이름은 주제를 알아볼 수 있게 정하고, 이름이 겹치는 별도 주제는 날짜나 구분자를 덧붙입니다.
- **입력 보관:** 사용자가 제공한 파일, 참고 자료, 요구사항은 해당 주제의 `input/`에 저장합니다. 대화로 받은 정보도 작업에 필요한 내용을 `input/requirements.md` 등에 기록합니다. 원본 파일은 보존합니다.
- **출력 보관:** 생성한 문서, 이미지, HTML, PDF 등 산출물은 해당 주제의 `output/`에 저장합니다. 중간 결과와 검증 자료도 필요하면 그 안의 하위 폴더로 구분합니다.
- **후속 작업:** 같은 주제의 수정이나 추가 요청은 기존 주제 폴더에서 이어서 작업합니다.
- **공통 자산과 주제 자료의 구분:** 개별 주제의 입력과 결과물을 `Skills/`에 섞지 않습니다. 문서 제작 과정에서 발견한 공통 개선은 해당 스킬에 반영하고, 주제별 내용은 `Projects/`에 유지합니다.

에이전트의 구체적인 작업 규칙은 [AGENTS.md](AGENTS.md)를 따릅니다.
